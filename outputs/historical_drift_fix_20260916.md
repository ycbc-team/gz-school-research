## 一、修复方案（全部在脚本/数据层）

### 1. build_entities.mjs —— 实体别名数据层修复
- `attachAlias` 新增 `force` 参数：官方录取裸名（如「广州市第一一三中学」「广州大学附属中学」）显式配置时绕过「纯名先占」拦截，挂到指定校区实体。
- 新增**跨 stage fallback**：官方名指向完中实体（如广附黄华路 stage=middle），按 poiName 全 stage 兜底挂别名。
- 数组多校区（2025 按学校整体招生）：**仅首校区挂纯名**，其余校区只挂校区限定名——避免同区同 stage 抢名（检查 [3]）。
- `OFFICIAL_MIDDLE_ALIAS` 补裸名 → 初中部校区（数据层直接分流，替代覆盖表硬编码）：
  - 「广州市第四中学」→ 津园校区（初中部）
  - 「广州中学」→ 五山校区（初中部）
  - 「广州大学附属中学」→ 黄华路校区（越秀派位裸名）
- `OFFICIAL_HIGH_ALIAS`：「广州大学附属中学」→ 大学城校区（高中录取分按学校整体招生）。

### 2. backfill_school_ids.py —— 回填规则升级 + 覆盖表
- `resolve` 升级为四级：norm 命中同 stage → loose 命中同 stage → 唯一候选接受（跨学段完中/一贯制）→ 多候选宁缺失。
- 新增**行政区过滤**（quota 带 district 字段）：本区先筛，本区无 → 回退全量唯一（跨区唯一 POI 引用允许）。
- 修复去重 bug：实体 name 与 alias 同串重复入索引导致「唯一」误判，按 (school_id, stage) 去重。
- **设施类 POI 剔除**：name 含「游泳馆/体育馆/运动场/田径场」的采集噪音不参与匹配（修复北师大广州实验被挂到「中学部游泳馆」POI）。
- **MATCH_OVERRIDES 覆盖表**（官方名 → school_id，37 条）：quota_matrix 人工修正结果固化进脚本，**四表共用**（quota / special_matrix / batch2_scores / district_quota 同一口径）。

### 3. build_scores.py —— 写盘 indent=1，与入库格式一致（消除全文件 diff 噪音）。

### 4. 测试层维护
