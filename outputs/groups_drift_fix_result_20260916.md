## 〇、本轮新增整改（相对上一版）

**① partial 纯源化 + 锚点表下沉（架构修正）**
- 7 区 `_partial_*.json` 已移除全部处理产物字段：成员 954 处 `school_id/poi_match/poi_name/campuses` + 33 处 `core_poi`。成员仅保留采集字段 `name/source_url/stage/verified`，集团不再带 `core_poi`。

- **禁止手改源数据**：partial 只接受采集新增/修正；锚点变更一律改锚点表并重跑生产脚本。

**② 九佛更名消除 2 处缺失（网络官方查证）**

- 缺失名单 10 → **8**。

**③ 多校区学校每校区独立实体关联（不再锚单一校区）**
- 锚点表成员支持 `school_ids[]` 多校区，产物成员多校区时 `school_id` 置空、全部校区展开为 `campuses[]`；`registry.ts` education 分支 `schoolIdToGroup` 索引全部 campuses 校区 → 每个校区实体独立命中集团，详情页各自显示品牌卡（`model.ts` isCurrent 按 campuses 判定）。
- 本轮展开的 3 处（上一版"保留源锚点待确认"项，现改为全校区关联）：
  - 华师附中实验小学 → 东 `db31a4f7` / 北 `1d697e07` / 南 `07bdec5f`（3 校区）
  - 广东第二师范学院实验中学（完中）→ 初中部 `014a9fb2` / 高中部 `33d95662`（2 校区）

## 三、代码/数据变更清单

**生产脚本（根因修复，杜绝"只改产物不改脚本"）**
- `scripts/match_poi.py`（v3 定型 + 收尾）：泛词后缀剥离、前导区名剥离、norm 区名归一、substring 双支、弱核心剔除（防九佛二中→二中科学城）、非学校词排除、远郊拦截后置、分校区回退+学段限定、alias 共享名不收敛
- `scripts/merge_groups.py`：
  - **锚点机制升级**：改读 `scripts/groups_anchors.json`（partial 不再承载锚点）；锚点命中→`已锚定`（单校区填 school_id，多校区 school_id 置空 + campuses 全校区展开）；未锚定才走 match_poi
  - group `core_poi` 从锚点表 `core_poi` 节回填（partial 已纯源化，产物 core_poi 不再丢失）
  - 调用 match_poi 传集团区 `preferred_adcode`、成员区名覆盖；`source_urls` 排序幂等；支持 argv 输出路径
- `scripts/check_groups_drift.py`（新增）：重跑生产脚本 vs 入库产物 diff（丢失/错配/新增），接入 `npm run check`
- `scripts/test_match_poi.py`：15 回归用例（新增九佛更名命中 2 例，更新京溪注释），接入 `npm run check`
- `package.json`：`check` 增加 匹配器回归 + 产物一致性两步（用户第 5 点"先跑生产脚本"）

**下游数据资源（非源数据）**
- `scripts/groups_anchors.json`（新增）：290 成员锚点（school_ids 可多校区）+ 33 组 core_poi；含九佛更名、华师附中实验/二师实验/京溪多校区
- 7 区 `_partial_*.json`：**纯源化**（954 处成员处理字段 + 33 处 core_poi 移除，仅剩 name/source_url/stage/verified）
- `brand_groups.json`：星悦/省实/广雅/二中/广附/华附/执信/铁一 school_ids 外键、清华附 source_url 补全、铁英主 POI 顺序调整
- `entities.json`：新增 2 处更名别名（知识城中学东校区=九佛中学、南校区=九佛第二中学，2024 并入）

**Shared/测试**
- `packages/shared/src/data/registry.ts`：brandSchoolIdToGroup 外键索引 + brandGroupResult；groupOfSchool 品牌分支外键优先、education 分支透传 campuses + **campuses 全校区索引**（多校区每校区独立实体命中）
- `packages/shared/src/domain/detail/model.ts`：品牌分支直接用 groupOfSchool 结果、education isCurrent 补 campuses 判定、brand stages 补外键学段
