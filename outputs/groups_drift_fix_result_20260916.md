## 三、代码/数据变更清单

**生产脚本（根因修复，杜绝"只改产物不改脚本"）**
- `scripts/match_poi.py`（v3 定型 + 本轮收尾）：
  - 泛词后缀剥离 `_GENERIC_SUFFIX`（含 初中部/小学部/高中部）
  - 前导区名剥离（`白云区广大附中实验中学(南校区)` ↔ POI `广大附中实验中学(南校区)` 精确命中）
  - norm 区名归一（`XX区`→`XX`）
  - substring 双支（A=成员核心在 POI / B=POI 核心在成员按位置收敛）
  - `_WEAK_CORE` 弱核心（区名/序数词 第一~第十）剔除，防"九佛第二中学→二中科学城"
  - `_NON_SCHOOL` 排除（bare 后 endswith，防"南悦中学→充电站/停车场"）
  - 远郊拦截移到 exact/alias 之后（POI 库自身含远郊 POI 如暨大附属增城实验学校，须先精确命中自己）
  - 2b5 分校区回退剥校区括号 + 学段限定优先（`云雅实验学校(初中部)` 不落到无括号主校）
  - alias 共享名（广铁一中铁英学校=番禺东/西校区别名）不再收敛到单一校区 → 合并招生保持缺失
- `scripts/merge_groups.py`：
  - **锚点机制**：school_id 非空=锚点保留、空=待匹配（不再重匹配人工锚定）
  - 调用 match_poi 时传集团区 `preferred_adcode`，成员名含区名时用成员区名覆盖
  - `source_urls` 排序（修 set 非确定性，产出幂等）
  - 支持 argv 输出路径（供 drift 校验）
- `scripts/check_groups_drift.py`（新增）：重跑生产脚本 vs 入库产物 diff（丢失/错配/新增），接入 `npm run check`
- `scripts/test_match_poi.py`（新增）：14 回归用例，接入 `npm run check`
- `package.json`：`check` 增加 匹配器回归 + 产物一致性两步（用户第 5 点"先跑生产脚本"）

**纯源数据（人工锚定/修正，非产物）**
- 7 区 `_partial_*.json`：白云 37 行、荔湾 10 行、黄埔 2 行、番禺 10 行（锚点修正/新增成员/补齐 campuses；错锚点如 景泰中学→本部、黄石学校→黄石校区、龙归学校→珑璟校区 修正；南悦/凤凰/江高镇中心/九佛系 标真实缺失）
- `brand_groups.json`：星悦/省实/广雅/二中/广附/华附/执信/铁一 school_ids 外键、清华附 source_url 补全、铁英主 POI 顺序调整
- `entities.json`：**本轮未改**（金广实验等经匹配器 B 支找回，不靠别名抢名）

**Shared/测试**
- `packages/shared/src/data/registry.ts`：brandSchoolIdToGroup 外键索引 + brandGroupResult；groupOfSchool 品牌分支 school_id 外键优先、education 分支透传 campuses
- `packages/shared/src/domain/detail/model.ts`：品牌分支直接用 groupOfSchool 结果、education isCurrent 补 campuses 判定、brand stages 补外键学段
- `detail-model.test.cjs`：覆盖断言 67→65（重跑产物后铁英小学/铁英中学/省实荔湾初中部/广雅荔湾/西关广雅南岸路 5 实体经 education 索引优先回归 education 分支）
