## 一、核心结论

1. **7区共整理出59所被网传列为"第一梯队/顶尖/名校"的公办小学**，全部标签均为民间口径、非官方认定。
2. **按A层官方客观数据核验**：21所有支撑、36所部分支撑、2所不支撑。
3. **"有支撑"学校的共性**：普遍具备"优质小升初出口（派位组内优质初中/对口直升优质初中）+ 教育集团核心校身份 + 大规模招生/学位预警"中至少两项官方客观信号。
4. **"省一级"历史称号不能作为现行区分维度**：如龙口西小学无省一级称号却公认第一梯队，而部分有省一级称号的学校网传仅列第二梯队，说明该标签在现行语境下参考价值有限。
5. **广州官方从不发布逐校升学率/成绩排名**，任何"普高率XX%"均为自媒体数字，本报告一律未采信。

## 二、核验方法与指标分层

### 网传名单采集
多来源交叉：广州妈妈网、本地宝、微信公众号/自媒体盘点（"丽丽在广州"等）、房产号（搜狐/网易/腾讯新闻/房王/房天下）、知乎/小红书帖子。每所学校标注哪些来源将其列为第一梯队、不同版本名单的差异。

### 客观指标分层（A/B/C三层）

| 层级 | 指标 | 说明 |
|---|---|---|
| **A层（主要依据）** | ①小升初出口结构 | 派位分组/对口直升表直接可得的组内初中构成与对口中学校名 |
| | ②教育集团身份 | 是否市/区教育集团核心校或成员校（截至2025底全市242个基础教育集团） |
| | ③招生规模 | 2026年区招生计划表的计划班数 |
| | ④学位预警 | 区教育局预警校名单 |
| **B层（辅助）** | 省一级/市一级历史称号 | 标注评定年份（1994-2006），仅作历史标注 |
| **C层（不采信）** | 学位房价格、民间口碑、自媒体升学率数字 | 仅标注，不作结论依据 |

### 关键政策口径
- **"省一级/市一级""重点学校"概念已取消**：2005年停评、2007年广州取消等级制、2010年全面取消审批（粤教督函〔2010〕2号）。现行只有"义务教育标准化学校"底线达标（无区分度）+ 优质均衡区 + 集团化办学 + 均衡编班。"省一级小学"名单是1994-2005年历史档案，只能作历史称号。
- **广州官方从不发布逐校升学率/成绩排名**，任何"普高率XX%"多为对口初中中考口径或自媒体/中介数据，不可采信。
- 若某校数据无法从公开官方文件获得，明确标注"未查到"，不得用第三方数字填补。

### 4.2 关键发现

1. **网传"第一梯队"与官方客观数据的对应度约36%**（21/59），超过六成学校仅获部分支撑或不支撑，说明民间标签与可验证的官方信号之间存在显著落差。
2. **老四区（越秀/荔湾/海珠/天河）的网传梯队概念更成熟**，名单版本差异较小；新四区（白云/黄埔/番禺）的"第一梯队"概念模糊，多以"省一级盘点""镇街中心校""集团名校"等形式出现，名单版本差异大。
3. **教育集团核心校身份是最强的单一官方信号**：21所有支撑学校中，15所为教育集团核心校（占71%）。
4. **省一级历史称号的区分度有限**：59所中39所有省一级称号，但其中18所仅获部分支撑、2所不支撑；同时龙口西小学无省一级称号却获有支撑，说明该历史称号在现行语境下不能作为区分维度。
5. **学位预警是"热门校"的客观信号**：在有支撑的21所中，11所有学位预警记录（占52%），预警从侧面反映学位需求旺盛。
6. **2所不支撑学校**（白云民航学校小学部、黄埔香雪小学）的共同特征：仅1个网传来源列为第一梯队、无省一级历史称号、无教育集团核心身份、无学位预警。
