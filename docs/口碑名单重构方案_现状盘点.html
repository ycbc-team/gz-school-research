04 · 重构方案

4.1 重构原则

  1. 来源时效门槛：仅认 2023 年及以后的榜单（2025 可参考）；2017 搜狐“省级小学盘点”等旧榜单作废，仅作历史备注，不计梯队证据。
  2. 来源共识门槛：仅“多个独立来源一致列梯队/口碑”才入列；单源、房产号独家、楼盘导向不计梯队证据。
  3. 官方客观事实门槛：省一级/示范性称号（按授牌年份客观记录）、区教育局办学绩效、教育集团归属（核心/成员）、学位预警（官方发布）——优先于一切自媒体。
  4. 出口实证门槛（升学反推）：小学看直升出口（直升一梯队初中=升学确定性）；初中看自主招生录取数、第二批次/名额分配表现、中考成绩——出口数据比口碑更硬。
  5. 现行主体门槛：停办/搬迁/并入他校的一律移出（如沙步→铁铮）；民办单独口径（摇号/自招，按出口成绩定梯队并显式标注民办）。
  6. 分级标准化：rumor_tier 统一为 第一梯队 / 第二梯队 / 第三梯队 三档 + 非梯队（地段热门）标注，废除自由文本。

4.4 处置规则与执行流程

处置动作

  • 保留一梯队：越秀/荔湾/海珠头部 + 市级名校系（约 15-20 所小学、20-25 所初中）
  • 降级：来源仅列“口碑不错”或 2 梯队 → 二/三梯队（石楼、南村、太和一等大量镇街校）
  • 剔除：停办（沙步）、单源无共识（民航/香雪/握山等）、tier1_eligible=false 却标一梯队（北师大广州实验、番禺执信）
  • 补录：官方实证强但漏收（如石碁镇中心小学——2018 绩效一等奖，现仅标“网传弱”）
  • 初中分档：用 scores_2025/2026 + batch2 出口数据把 54 所“全一梯队”拆成三档
  • 民办标注：9 所民办单独口径 + 显式标注

执行阶段

  1. 口径统一：rumor_tier 标准化三档 + 来源时效（2023+）与 tier1_eligible 语义确认
  2. 逐校核验：113 所按“来源时效→共识→官方客观事实→出口实证→现行主体”五关核验；出口数据用项目已有资产直接计算（自招数/直升/名额分配/中考）
  3. 分档定稿：输出新版名单（含分级依据记录、school_ids 全量补齐、移出/降级清单）
  4. 前端适配（UI 展示口径）：UI 永不展示"第一/二/三梯队"文字；口碑 Badge 仅授予 tier_rank===1（第一梯队）；tier_rank 2/3 学校仍在 SupportView/信息卡展示口碑信息，依据列显示 conclusion_basis 客观说明（如"绩效二等奖·集团成员""2023+ 口碑·无实证"）；tier_rank null（剔除，含停办）移出口碑列表
