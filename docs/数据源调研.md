# 学校信息与招生数据源调研

> 调研时间：2026-09-08 · 范围：广州市 7 区（荔湾/越秀/海珠/天河/白云/黄埔/番禺）小学
> 用途：为离线学校数据库确定权威数据源与采集方案

## 一、结论速览

1. **学校基础信息**（名称/地址/坐标）：现有高德 POI 快照可用（已入库），地址与电话以**各区教育局招生文件附表**核对补全。
2. **公办小学招生**：**地段入学**——招生地段由**区教育局每年公布**，是唯一权威依据（"人户一致"地段生按地段对口，超额时按区细则统筹/排序）。
3. **民办小学招生**：**电脑派位（摇号）**，**没有地段概念**；报名人数超计划即摇号，填报 1–2 个平行志愿、按户籍/学籍/证件地址选一个区报名。
4. **数据时效**：各区**每年 4 月底**发布当年招生细则/地段，地段"保持相对稳定"但**每年可能微调**→ 数据库须**按年建表**，保留历年便于对比趋势。

### B 级：官方补充（用于核对细节）

- 各校官网/公众号：招生简章、新生摸查通知（如越秀中星/登峰小学摸查）
- 区政府门户政务公开栏目：政策文件库（gz.gov.cn/gzzcwjk）

### C 级：第三方聚合（仅交叉参考，不作为依据）

- 广州本地宝学区划分页（聚合整理，更新快但可能滞后/错漏）
- 媒体报道（羊城晚报/南方+/广州日报）：政策解读、热点校地段分析

### D 级：已有数据

- 高德 POI 快照：619 所小学名称/坐标/区属（`data/schools-gz.json`，2026-09-08）

## 三、关键政策口径（2026 年）

- **公办小学**：按区教育局划定**招生地段**就近入学（居住地与学校直线距离原则上 ≤3 公里）；"人户一致"优先；"人户不一致"由区统筹；个别学校超额按各区细则排序（如天河 5 校按房产时间先后）。
- **民办小学**：报名人数 ≤ 计划 → 直接录取；＞ 计划 → 全区统一**电脑派位**（2026-06-12）；可填 1–2 个平行志愿。
- **报名入口**：统一在广州市义务教育学校招生报名系统（zs.gzeducms.cn）网上报名。

## 四、离线数据库结构建议

```
data/
├── schools-gz.json            # 已有：619 所小学基础点位（name/lng/lat/adcode）
├── school_profiles.json       # 学校档案：地址、电话、性质（公办/民办）、办学层级、所属教育指导中心
├── enrollments/
│   └── 2026.json              # 按年：招生方式、计划班数/人数、地段范围、来源链接
└── policies/
    └── 2026.json              # 各区学位安排规则（人户一致/统筹/排序）、民办摇号安排
```

### 字段设计

**school_profiles.json**（每校一条，主键 school_id=名称+adcode）

```jsonc
{
  "id": "440103_xxx小学",
  "name": "xxx小学",
  "adcode": "440103",
  "district": "荔湾区",
  "address": "…",
  "phone": "…",
  "nature": "公办|民办",
  "level": "省一级|市一级|区一级|null",
  "edcenter": "所属教育指导中心",        // 白云/番禺按片划分
  "source": "amap|区教育局2026附表",
  "updated": "2026-09-08"
}
```

**enrollments/2026.json**（每校×每招生方式一条）

```jsonc
{
  "school_id": "…",
  "year": 2026,
  "way": "地段|摇号|直升|积分|统筹",     // 民办=摇号，公办=地段
  "plan_classes": 8,                     // 计划班数
  "plan_count": null,                    // 计划人数（若有）
  "zone_text": "原表原文",               // 保留官方原文，避免转述失真
  "zone_struct": {                       // 结构化地段（尽力抽取）
    "streets": ["珠光街"],
    "communities": ["阳光居委", "槎龙居委"],
    "estates": ["保利天瑞"],
    "note": "门牌号范围见原文"
  },
  "source_url": "https://…",
  "updated": "2026-05-01"
}
```

## 五、采集方案与工作量

| 环节 | 方式 | 说明 |
| --- | --- | --- |
| 文件获取 | 脚本抓取各区官网 PDF/网页 + 人工补齐 | 各区 URL 结构各异，需逐区适配 |
| 解析 | pdfplumber / 表格抽取 + 人工校对 | 越秀=门牌号级表格、白云=居委级表格、天河=文字细则，格式异构，**必须人工复核** |
| 民办校 | 报名系统招生简章/计划 | 只录计划数+摇号政策，无地段 |
| 更新 | 每年 5 月刷新当年 enrollments | 保留历年文件，不做覆盖删除 |

**预估工作量**：7 区 619 校的地段结构化是主要成本（越秀门牌级、白云居委级表述颗粒度不一），建议按"官方原文入库 + 结构化字段尽力抽取 + 人工抽检"推进，避免为追求 100% 结构化而卡住主流程。

## 六、风险与注意

- 地段以**当年区教育局公布为准**，第三方聚合（本地宝等）仅供参考，可能与官方不一致。
- 民办摇号结果/录取数据**不属于公开离线数据**（仅摇号时间与政策公开），数据库只存"招生方式+计划"。
- 学位预警（如天河 2027 年 13 校预警）是重要决策信息，可另建字段记录。
