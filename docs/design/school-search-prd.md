# 广州学校升学调研小程序 · 产品需求文档（PRD）

> 本文档定义「学校搜索」模块的产品功能需求与业务规则。
> 界面视觉、交互动效、组件样式等 UE/UI 规范见同级文件 `school-search-ui-spec.html`。
> 适用范围：广州学途小程序「学校搜索」模块（小学 / 初中 / 高中）。
> 版本：基于 UI 稿 R6–R12 整理。
>
> **数据字段引用约定**：本手册凡涉及「读取数据字段进行信息展示」的需求点，均在对应页面下方列「数据字段引用」，标明字段所属的**数据表（JSON 真源）/ 运行时结构**、**字段名**、**取值与内容示例**，便于研发按图索骥。数据真源唯一：`data/*.json`；双端（Web / 小程序）运行时结构见 `packages/shared`。
>
> **学段配色口径说明**：地图学段分色为**本小程序 UI 自定**（小学蓝 `#2F5CD6` / 初中橙 `#E8850C` / 高中绿 `#0F9D58`），**不沿用项目老代码 `STAGE_COLOR`（紫/红/绿）**；项目代码配色仅作历史参考，已被本 UI 稿取代。学段**取值**（数据字段）严格以项目结构表为准（见各屏「数据字段引用」）。

## 全局需求（跨页面）

- **小程序名称**：广州学途。
- **运行形态**：微信小程序；右上角系统胶囊（··· 更多 / ⊕ 退出小程序）为微信原生元素，常驻所有页面（地图层、搜索页、详情页、异常态），不可自定义。
- **底部导航**：原生 tabBar，两项 —— 首页 / 政策；当前项高亮。
- **视觉基调**：主题色知性蓝 #2F5CD6；四类标签色（行政区 / 学段 / 示范等级 / 办学性质）按原型表建立。
- **标签展示规则（全局）**：① 行政区标签**固定为全名并带「区」字**（如「荔湾区」「越秀区」），不省略「区」；② 同一学校若含**多个学段**，按学段**拆成多枚独立学段标签并排展示**（如「小学」「初中」），**不合并写成一枚「初中/高中」**（适用于联想词条、集团成员行等列表场景）；③ 同一类别多个取值一律拆成多枚标签，不合并进一枚；④ **详情卡例外**：多学段学校的详情卡（半窗 / 全屏）头部「学段」标签**只展示当前选中 tab 对应的学段**（tab 条本身罗列该校全部学段，见 06C / 07B）。
- **招生方式标签（全局通用）**：详情卡「招生计划（2026年）」模块标题右侧的规则标签，**无独立样式、并入通用标签体系**（方角 Tag，中标签档：高 24 / r=6 / 12px，不加描边；「招生方式」类＝知性蓝浅调：底 #F2F6FE / 字 #254BAE；UI 图见 UI 稿第 01 节「通用 · 标签样式（Tag）」与「通用 · 招生方式标签」）；文案共 **3 种**，随该学段招生方式切换，同一时刻只显示一枚：**单校划片 / 多校电脑派位 / 单校电脑抽签**（与 `mechanism` 枚举映射见 07B）。
- **筛选栏胶囊规则（全局）**：筛选栏三个维度胶囊（行政区 / 学段 / 办学性质）**只显示维度名**，圈定筛选项后**不显示任何已选数量角标或数字**。
- **地图默认视野**：广州中心城区中轴线（珠江新城 — 广州塔一带）。
- **定位授权（后续版本）**：首次进入接入定位授权弹窗；用户拒绝授权时保持默认视野，不影响使用。
- **画布基准**：手机框 375 × 812。

## 01 首页（地图层）

1. 首页以整屏真实地图为背景，按真实地理位置预置学校点位。
2. 提供悬浮搜索框入口，占位「搜索广州小初高学校」；点击进入搜索页。
3. 筛选栏提供三个维度入口：行政区 / 学段 / 办学性质；点击呼出对应维度的筛选半窗。三胶囊**只显示维度名，不显示已选数量角标或数字**（见「全局需求·筛选栏胶囊规则」）。
4. 左下角图例区说明点位三色含义：小学 / 初中 / 高中（具体颜色见「数据字段引用」）；**图例另含「多学段」条目**（见第 9 条）。
5. 底部导航两项（首页 / 政策），点击切换、当前项高亮。
6. 地图支持双指缩放、单指拖动。
7. 点击学校点位 → 底部弹出半窗学校卡（默认约 45% 屏高，约 365px／812 屏），该点位进入选中态。
8. 页面默认按广州中心城区中轴线视野展示。
9. **多学段点位（需求层）**：同一学校实体可能同时含多个学段（如九年一贯制含小学 + 初中、十二年一贯制含小学 + 初中 + 高中）。地图将点位按 `school_id` 或同址坐标合并为**一个多学段点位**，图例须新增「多学段」分类条目；多学段点位以"所含各学段色拼合"区分（具体视觉拼合方式见 UI 稿 06 帧规范）。

**数据字段引用（本屏展示所用）**

- **学段判定**：`data/registry/entities.json` → `entities[].stage`（类型 `SchoolStage = 'primary' | 'middle' | 'high'`）。
  - 取值示例：小学 → `'primary'`（示例实体 `school_id=gz-440105-9aac697e`，名称"万松园小学(云桂校区)"）；初中 → `'middle'`（示例 `school_id=gz-440103-53cac770`，"广东实验中学荔湾学校(初中部)"）；高中 → `'high'`（示例 `school_id=gz-440103-3aca532e`，"广东实验中学(高中部)"）。
- **学段标签（展示文案，真实映射）**：`packages/shared/src/domain/map/constants.ts` → `STAGE_LABEL = { primary:'小学', middle:'初中', high:'高中' }`（用于详情卡学段标签 / 联想词条标签）。
- **学段配色（视觉，UI 自定）**：本小程序 UI 指定为 小学蓝 `#2F5CD6` / 初中橙 `#E8850C` / 高中绿 `#0F9D58`（见 UI 稿图例与规范表）；**不沿用项目老代码 `STAGE_COLOR` 的紫/红/绿**。
- **点位坐标与落位**：`data/{primary,middle,high}/schools-gz.json` → `{ ..., schools: [...] }`，每条含 `name, lng, lat, adcode, school_id`（高中文件另含 `school`）；点位合并后运行时结构 `MapPoint`（`packages/shared/src/domain/map/filters.ts`，由 `points.ts` 的 `buildPoints` 生成），其 `stages: SchoolStage[]` 记录该点位所含学段（单学段长度 1，多学段长度 2–3）。
  - 多学段真实示例：`school_id=gz-440113-000bd12e`，名称"万翔学校"，`stages=['primary','middle']`（小学 + 初中，九年一贯制）→ 地图上该点位由小学色(蓝 `#2F5CD6`) + 初中色(橙 `#E8850C`) 拼合显示（各半圆）。全库共 183 个 school_id 跨多学段。
- **行政区归属**：`schools-gz.json` 的 `schools[].adcode` → `constants.ts DISTRICTS`（七区 `adcode`/`name`/`color`，如荔湾 `440103`、越秀 `440104`、海珠 `440105`、天河 `440106`、白云 `440111`、黄埔 `440112`、番禺 `440113`）；`districtByAdcode` 提供 adcode → 区名映射。

## 02 搜索页 · 默认态

1. 入口：点击首页搜索框弹出本页。
2. 页面组成：搜索栏 + 历史记录区 + 推荐搜索区 + 键盘区。
3. 搜索栏：含返回按钮、默认占位词「支持广州小初高学校搜索」；搜索栏头行与微信原生胶囊（··· / ⊕）**顶部对齐、同行同高**（头行高 44px、搜索框 32px 行内垂直居中），对齐实现口径见 UI 稿「小程序胶囊」规范表。
4. 搜索按钮：无输入时不展示；有输入内容后才出现并可点击。
5. 历史记录区：仅在存在历史词条时展示，按搜索时间倒序，以胶囊平铺自动换行呈现；右侧「清空」触发二次确认弹窗（见 11）。
6. 推荐搜索区：展示省市属高中，按拼音首字母排序（排名不分先后）。
7. 进入页面自动唤起键盘。
8. 返回：点击返回按钮或左滑手势回到来源页（默认首页）；从筛选半窗搜索入口进入时，返回直接回首页且筛选半窗保持收起。
9. 执行搜索：
   - 有结果 → 关闭搜索页回到首页，地图定位到结果学校、点位选中并自动拉起详情卡半窗（见 06B）。
   - 无结果 → 进入异常态 A（见 08）。

**数据字段引用（本屏展示所用）**

- **推荐搜索（省市属高中）**：`data/high/levels.json` → `{ schools: [...] }`，每条含 `name, district, category('普通高中'|'省市属示范'|'区属示范'), campuses, aliases`（另含 `affiliation, demo, indicators`）；按 `name` 拼音首字母排序展示（排名不分先后）。
- **历史记录**：端上本地缓存（非服务端数据表），按搜索时间倒序；仅存在时展示。

## 03 搜索页 · 联想词态

1. 输入即联想，支持三种匹配：精确 / 模糊 / 别名；优先展示精确匹配，无精确结果时展示模糊匹配。
2. 排序规则：模糊结果按关联度排序；关联度相同按行政区（荔湾 > 越秀 > 海珠 > 天河 > 白云 > 黄埔 > 番禺）；行政区相同按学段（小学 > 初中 > 高中）。
3. 词条右侧显示学校标签：行政区、学段。行政区标签**固定为全名并带「区」字**（如「荔湾区」）；若该学校含**多个学段**，按学段**拆成多枚独立学段标签并排**（如「小学」「初中」），**不合并写成一枚「初中/高中」**。
4. 联想词条区铺满全页，词条过多时支持上下滑动。
5. 执行搜索：点击「搜索」按钮或任一联想词条 → 执行搜索（结果处理同 02 第 9 条）。

**数据字段引用（本屏展示所用）**

- **联想匹配源**：`data/registry/entities.json` → `entities[].name` / `entities[].aliases`（精确 / 模糊 / 别名三种匹配），命中后取 `stage` 作为学段标签、`school_id` 作为跳转键。
- **排序依据**：关联度（模糊匹配 score）→ 行政区序（`DISTRICTS` 顺序：荔湾 > 越秀 > 海珠 > 天河 > 白云 > 黄埔 > 番禺）→ 学段序（`STAGE_PRIORITY`：小学 > 初中 > 高中，即 primary < middle < high）。
- **词条右侧标签**：行政区 `districtByAdcode[adcode]`（**全名带「区」字**） + 学段 `STAGE_LABEL[stage]`；多学段学校 `stages: SchoolStage[]`（长度 2–3）**逐学段拆成多枚标签**，不合并为一枚。

## 04 筛选栏半窗 · 状态 A（行政区）

1. 入口：点击筛选栏某一维度胶囊 → 底部弹出筛选半窗。
2. 半窗组成：搜索入口 + 维度切换 + 选项区；同一时刻只展示当前选中维度的选项。
3. 选项默认全选，支持多选；左下角「全不选」、右下角「确认」。
4. 维度切换：点击其他维度胶囊，选项组整组切换，各维度已选状态各自保留。
5. 「确认」→ 应用筛选并收起半窗；点返回或半窗外区域 → 关闭且不保存已选。
6. 半窗内搜索入口 → 收起半窗并跳转搜索页；此时搜索页点返回直接回首页，半窗保持收起。
7. **确认后视野自适应**：确认时若**行政区维度发生变化且收窄**（非七区全选），地图视野自动缩放到能容纳筛选后全部可见点位的范围，避免「人停在 A 区、筛了 B 区、地图却不动」的错位；学段 / 办学性质属**属性维度**、不改变学校地理位置，故不移动相机；筛选结果为 0 时不移动（转异常态 C 见 10）。

**数据字段引用（本屏展示所用）**

- **行政区选项枚举**：`constants.ts DISTRICTS`（七区 `name`/`adcode`），默认全选。

## 05 筛选栏半窗 · 状态 B（学段）

1. 同一半窗内点击「学段」维度 → 选项区整组切换为学段选项：小学 / 初中 / 高中（高中分组为省市属示范、区属示范、其他学校）。
2. 切换维度不重置其他维度已选状态；「全不选」仅作用于当前维度。
3. 点击「办学性质」同理，切换为公办 / 民办。
4. 其余交互同状态 A。

**数据字段引用（本屏展示所用）**

- **学段选项枚举**：`constants.ts STAGE_TABS = [{v:'primary',l:'小学'},{v:'middle',l:'初中'},{v:'high',l:'高中'}]`；高中维度内部分组 `GRADE_GROUPS`：`hM 市重点(省市属示范)` / `hD 区重点(区属示范)` / `hN 普通高中`。
- **办学性质选项枚举**：`constants.ts SCHOOL_NATURE_TABS = [{v:'public',l:'公办'},{v:'private',l:'民办'}]`；性质真源为 `entities[].nature`（仅"民办"才写字段，公办缺省即公办）。

## 06 地图层（点位选中 / 详情卡）

1. 整屏真实地图背景；点位为真实学校按实际位置落点（示例数据：小学 4、初中 1、高中 4）。
2. 点击学校点位 → 底部弹出半窗学校卡（默认约 45% 屏高），该点位进入选中态（放大至 22、**知性蓝外圈光晕**、**名称气泡常显校名**、zIndex 置顶）；点击其他点位切换卡片。
3. 半窗卡内容：校名 + 行政区 / 学段 / 办学性质三标签，下方复用详情长图内容按半窗高度截取可视部分，底部渐隐，提供「展开详情」。行政区标签**固定带「区」字**；**多学段学校的学段标签只显示当前选中 tab 对应的学段**（见第 4 条与 UI 稿 06C），单学段学校显示该校学段（多学段拼圆视觉见 UI 稿 06 帧规范）。
4. **多学段半窗卡（tab）**：多学段学校半窗卡的**学段 tab 条位于半窗卡最上方**（拖拽 handle 之下、校名之上）——压缩版胶囊式 tab，**顺序按学段优先级 高中 > 初中 > 小学 排列**，**tab 左对齐下方文字的左缘、按内容宽度排列（不拉伸占满整行）**，tab 数量＝实际学段 2–3 枚（不显示不存在的学段），色点同全屏版，默认选中主学段；**tab 之下才是校名与三标签**；点 tab 半窗内校名 / 学段标签 / 预览模块整体刷新为该学段内容；上滑展开全屏后 tab 选中状态延续（见 UI 稿 06C / 07B）。**地图左下角图例保持原位、不因半窗弹出而移动**（半窗为最上层，展开时自然遮住图例）。
5. 半窗 ↔ 全屏：
   - 上滑 / 点「展开详情」/ 点卡片内容 → 展开为全屏详情长图（见 07）。
   - 全屏页下滑 / 点返回 → 收起回半窗卡。
   - 点 ✕ 或半窗卡以外区域 → 关闭卡片。
5. 详情卡为最上层，覆盖底部导航 tab（收起卡片后才露出）。
6. **多学段点位**：同 01 第 9 条；多学段点位视觉拼合方式（扇形拼圆）见 UI 稿 06 帧规范；多学段半窗卡（压缩版 tab）见第 4 条与 UI 稿 06C。

**数据字段引用（本屏展示所用）**

- **半窗卡三标签**：行政区 `districtByAdcode[adcode]`（**全名带「区」字**）、学段 `STAGE_LABEL[...]`（**单学段取该校学段；多学段 tab 态取当前选中 tab 对应学段，单枚展示**）、办学性质 `MapPoint.natureOf[mainStage]`（源自 `entities.nature`）。
  - 多学段点位的「主学部」`mainStage` = 该点位所含学段中优先级最高者：`STAGE_PRIORITY = { primary:0, middle:1, high:2 }`，即 高中 > 初中 > 小学（`points.ts:175` 取排序后末位）。半窗卡的学段 / 办学性质标签及详情跳转按主学部取值；**点位本身不做舍弃**，仍按所含全部学段拼圆展示（见 01 第 9 条）。
- **选中态 / 名称气泡**：运行时视觉，无独立数据字段。
- **点位与学段**：同 01「数据字段引用」（点位来自 `data/{primary,middle,high}/schools-gz.json` 的 `schools[]`，学段来自 `entities[].stage`，合并后 `MapPoint.stages`）。

## 06B 搜索执行后 · 回到首页定位态

1. 触发：在搜索页执行搜索且「有结果」时。
2. 交互链路：关闭搜索页回到首页地图层 → 地图自动定位并缩放至结果学校 → 该点位进入选中态（放大至 22 + **知性蓝外圈光晕** + **名称气泡常显校名**）→ 自动拉起学校详情卡半窗（内容与直接点击点位进入一致）。
3. 详情卡内点击其他学校名（升学路线 / 教育集团链接）→ 重复上述链路（定位新学校、点位选中、刷新半窗卡）。
4. 点击当前正在查看的学校名 → 不跳转，提示 toast「已在当前学校」（轻提示，约 1.5s 自动消失）。

**数据字段引用（本屏展示所用）**

- 定位目标点位取 `MapPoint`（结构同 01 / 06）；其余为交互链路，无新增数据字段。搜索命中键为 `entities[].school_id` / `entities[].aliases`（见 03 数据字段引用）。

## 06C 地图层 · 多学段半窗卡（tab）

1. 场景：点击**多学段点位**（同一 `school_id` 跨 ≥2 学段）时弹出的半窗学校卡，示例校为万翔学校（九年一贯制，小学 + 初中）。
2. 半窗高度：默认约 45% 屏高（约 365px／812 屏），单屏可见「学校信号 + 招生计划」两个顶部模块，底部渐隐 + 「展开详情」。

## 09 异常态 B · 网络加载失败

1. 触发：详情 / 列表接口超时或返回失败时，内容区替换为加载失败态；顶部导航保持可用。
2. 主操作「重新加载」：局部重试，仅重新请求失败的模块，不整页刷新。
3. 连续 2 次重试仍失败 → 按钮下方追加「反馈问题」文字入口。
4. 加载中状态：请求期间该模块展示骨架屏；超过 10s 未返回自动转为本态。

**数据字段引用（本屏展示所用）**：重试请求的是各模块对应数据接口（模块与字段对照见 07「数据字段引用」）；局部重试仅重拉失败模块。

## 10 异常态 C · 筛选结果为空

1. 触发：筛选条件组合在当前地图视野内无匹配点位时，地图中央弹出异常提示弹窗（样式走全局弹窗统一规格，宽 240px）。
2. 地图场景弹窗不加遮罩，缩放 / 拖动手势仍可用，用户可先调整视野再决定是否重置。
3. 关闭：弹窗右上角提供「×」关闭按钮，点「×」仅关闭弹窗、保留当前筛选；主操作「重置筛选」恢复全部维度默认全选并关闭弹窗。
4. 同一规则适用于首页地图层；搜索结果页如遇同类情况，复用异常态 A 的空状态。

**数据字段引用（本屏展示所用）**：筛选匹配依赖 `entities[].stage` / `entities[].nature` 与 `DISTRICTS` 枚举（见 01 / 05）；本态本身无新增字段。

## 11 通用弹窗 · 清空历史确认

1. 触发：搜索页点「清空」弹出本弹窗。
2. 复用原则：后续所有破坏性 / 不可逆操作（清空历史、重置全部筛选等）统一复用本对话框样式，不再各自定义。
3. 「清空」→ 清空全部历史词条、关闭弹窗并隐藏历史记录区（推荐搜索区自动上移）。
4. 「取消」或系统返回键 → 仅关闭弹窗，历史记录保留原状。

**数据字段引用（本屏展示所用）**：历史词条为端上本地缓存（见 02），清空即清除该缓存，无服务端字段。
