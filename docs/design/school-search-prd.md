# 广州学校升学调研小程序 · 产品需求文档（PRD）

> 本文档定义「学校搜索」模块的产品功能需求与业务规则。
> 界面视觉、交互动效、组件样式等 UE/UI 规范见同级文件 `school-search-ui-spec.html`。
> 适用范围：广州学途小程序「学校搜索」模块（小学 / 初中 / 高中）。
> 版本：基于 UI 稿 R6–R10 整理。

## 全局需求（跨页面）

- **小程序名称**：广州学途。
- **运行形态**：微信小程序；右上角系统胶囊（··· 更多 / ⊕ 退出小程序）为微信原生元素，常驻所有页面（地图层、搜索页、详情页、异常态），不可自定义。
- **底部导航**：原生 tabBar，两项 —— 首页 / 政策；当前项高亮。
- **视觉基调**：主题色知性蓝 #2F5CD6；四类标签色（行政区 / 学段 / 示范等级 / 办学性质）按原型表建立。
- **地图默认视野**：广州中心城区中轴线（珠江新城 — 广州塔一带）。
- **定位授权（后续版本）**：首次进入接入定位授权弹窗；用户拒绝授权时保持默认视野，不影响使用。
- **画布基准**：手机框 375 × 812。

## 01 首页（地图层）

1. 首页以整屏真实地图为背景，按真实地理位置预置学校点位。
2. 提供悬浮搜索框入口，占位「搜索广州小初高学校」；点击进入搜索页。
3. 筛选栏提供三个维度入口：行政区 / 学段 / 办学性质；点击呼出对应维度的筛选半窗。
4. 左下角图例区说明点位三色含义：小学蓝 / 初中橙 / 高中绿。
5. 底部导航两项（首页 / 政策），点击切换、当前项高亮。
6. 地图支持双指缩放、单指拖动。
7. 点击学校点位 → 底部弹出半窗学校卡（默认约 25% 屏高），该点位进入选中态。
8. 页面默认按广州中心城区中轴线视野展示。

## 02 搜索页 · 默认态

1. 入口：点击首页搜索框弹出本页。
2. 页面组成：搜索栏 + 历史记录区 + 推荐搜索区 + 键盘区。
3. 搜索栏：含返回按钮、默认占位词「支持广州小初高学校搜索」。
4. 搜索按钮：无输入时不展示；有输入内容后才出现并可点击。
5. 历史记录区：仅在存在历史词条时展示，按搜索时间倒序，以胶囊平铺自动换行呈现；右侧「清空」触发二次确认弹窗（见 11）。
6. 推荐搜索区：展示省市属高中，按拼音首字母排序（排名不分先后）。
7. 进入页面自动唤起键盘。
8. 返回：点击返回按钮或左滑手势回到来源页（默认首页）；从筛选半窗搜索入口进入时，返回直接回首页且筛选半窗保持收起。
9. 执行搜索：
   - 有结果 → 关闭搜索页回到首页，地图定位到结果学校、点位选中并自动拉起详情卡半窗（见 06B）。
   - 无结果 → 进入异常态 A（见 08）。

## 03 搜索页 · 联想词态

1. 输入即联想，支持三种匹配：精确 / 模糊 / 别名；优先展示精确匹配，无精确结果时展示模糊匹配。
2. 排序规则：模糊结果按关联度排序；关联度相同按行政区（荔湾 > 越秀 > 海珠 > 天河 > 白云 > 黄埔 > 番禺）；行政区相同按学段（小学 > 初中 > 高中）。
3. 词条右侧显示学校标签：行政区、学段。
4. 联想词条区铺满全页，词条过多时支持上下滑动。
5. 执行搜索：点击「搜索」按钮或任一联想词条 → 执行搜索（结果处理同 02 第 9 条）。

## 04 筛选栏半窗 · 状态 A（行政区）

1. 入口：点击筛选栏某一维度胶囊 → 底部弹出筛选半窗。
2. 半窗组成：搜索入口 + 维度切换 + 选项区；同一时刻只展示当前选中维度的选项。
3. 选项默认全选，支持多选；左下角「全不选」、右下角「确认」。
4. 维度切换：点击其他维度胶囊，选项组整组切换，各维度已选状态各自保留。
5. 「确认」→ 应用筛选并收起半窗；点返回或半窗外区域 → 关闭且不保存已选。
6. 半窗内搜索入口 → 收起半窗并跳转搜索页；此时搜索页点返回直接回首页，半窗保持收起。

## 05 筛选栏半窗 · 状态 B（学段）

1. 同一半窗内点击「学段」维度 → 选项区整组切换为学段选项：小学 / 初中 / 高中（高中分组为省市属示范、区属示范、其他学校）。
2. 切换维度不重置其他维度已选状态；「全不选」仅作用于当前维度。
3. 点击「办学性质」同理，切换为公办 / 民办。
4. 其余交互同状态 A。

## 06 地图层（点位选中 / 详情卡）

1. 整屏真实地图背景；点位为真实学校按实际位置落点（示例数据：小学 4、初中 1、高中 4）。
2. 点击学校点位 → 底部弹出半窗学校卡（默认约 25% 屏高），该点位进入选中态（放大高亮 + 名称气泡）；点击其他点位切换卡片。
3. 半窗卡内容：校名 + 行政区 / 学段 / 办学性质三标签，下方复用详情长图内容按半窗高度截取可视部分，底部渐隐，提供「展开详情」。
4. 半窗 ↔ 全屏：
   - 上滑 / 点「展开详情」/ 点卡片内容 → 展开为全屏详情长图（见 07）。
   - 全屏页下滑 / 点返回 → 收起回半窗卡。
   - 点 ✕ 或半窗卡以外区域 → 关闭卡片。
5. 详情卡为最上层，覆盖底部导航 tab（收起卡片后才露出）。

## 06B 搜索执行后 · 回到首页定位态

1. 触发：在搜索页执行搜索且「有结果」时。
2. 交互链路：关闭搜索页回到首页地图层 → 地图自动定位并缩放至结果学校 → 该点位进入选中态 → 自动拉起学校详情卡半窗（内容与直接点击点位进入一致）。
3. 详情卡内点击其他学校名（升学路线 / 教育集团链接）→ 重复上述链路（定位新学校、点位选中、刷新半窗卡）。
4. 点击当前正在查看的学校名 → 不跳转，提示 toast「已在当前学校」（轻提示，约 1.5s 自动消失）。

## 07 学校详情卡 · 小学（长图）

1. 入口：地图层点选点位 → 半窗学校卡 → 上滑 / 点「展开详情」→ 全屏长图详情页；全屏页下滑可回半窗卡，点返回 / 关闭 / 卡片外空白关闭。
2. 详情页模块（自上而下）：学校信号 → 招生计划（2026）→ 升学路线参考（2026）→ 所在区招生细则（2026）→ 教育集团。
   - 学校信号：含学位预警 / 省一级 / 多维印证；标题右侧附「民间口径」小字说明。
   - 招生计划：计划班数 / 数据来源 / 招生地段；无具体信息的字段不展示。
   - 升学路线参考：仅列对口学校名（不带标签）；学校名为可点击链接。
   - 所在区招生细则：对应区招生政策说明。
   - 教育集团：三级层级——模块标题（一级）；成员类型「所属集团 / 同一法人单位 / 独立法人单位」（二级）；成员校（三级）。
3. 链接交互：升学路线 / 教育集团内学校名为可点击链接，点击跳转地图定位（同 06B 链路）；点击当前学校 → toast「已在当前学校」。
4. 范围：小学详情先出；初中 / 高中详情待指定后补充。

## 08 异常态 A · 搜索无结果

1. 触发：精确 + 模糊 + 别名三种匹配均无结果时，联想词条区替换为空状态。
2. 空状态四要素：插画 + 标题 + 说明 + 主操作。
3. 主操作「清空并重新搜索」：清空输入词并重置全部筛选条件，回到搜索页默认态。
4. 空状态下不展示历史记录区 / 推荐搜索区，避免与空态信息互相干扰。

## 09 异常态 B · 网络加载失败

1. 触发：详情 / 列表接口超时或返回失败时，内容区替换为加载失败态；顶部导航保持可用。
2. 主操作「重新加载」：局部重试，仅重新请求失败的模块，不整页刷新。
3. 连续 2 次重试仍失败 → 按钮下方追加「反馈问题」文字入口。
4. 加载中状态：请求期间该模块展示骨架屏；超过 10s 未返回自动转为本态。

## 10 异常态 C · 筛选结果为空

1. 触发：筛选条件组合在当前地图视野内无匹配点位时，地图中央弹出半透明浮层提示。
2. 浮层不遮挡地图手势（缩放 / 拖动仍可用），用户可先调整视野再决定是否重置。
3. 主操作「重置筛选」：恢复全部维度默认全选并收起浮层；点浮层外区域仅关闭浮层、保留当前筛选。
4. 同一规则适用于首页地图层；搜索结果页如遇同类情况，复用异常态 A 的空状态。

## 11 通用弹窗 · 清空历史确认

1. 触发：搜索页点「清空」弹出本弹窗。
2. 复用原则：后续所有破坏性 / 不可逆操作（清空历史、重置全部筛选等）统一复用本对话框样式，不再各自定义。
3. 「清空」→ 清空全部历史词条、关闭弹窗并隐藏历史记录区（推荐搜索区自动上移）。
4. 「取消」或系统返回键 → 仅关闭弹窗，历史记录保留原状。
