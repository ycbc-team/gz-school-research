# 广州学校升学调研小程序 · 产品需求文档（PRD）

> 本文档定义「学校搜索」模块的产品功能需求与业务规则。
> 界面视觉、交互动效、组件样式等 UE/UI 规范见同级文件 `school-search-ui-spec.html`。
> 适用范围：广州学途小程序「学校搜索」模块（小学 / 初中 / 高中）。
> 版本：基于 UI 稿 R6–R12 整理。
>
> **数据字段引用约定**：本手册凡涉及「读取数据字段进行信息展示」的需求点，均在对应页面下方列「数据字段引用」，标明字段所属的**数据表（JSON 真源）/ 运行时结构**、**字段名**、**取值与内容示例**，便于研发按图索骥。数据真源唯一：`data/*.json`；双端（Web / 小程序）运行时结构见 `packages/shared`。
>
> **学段配色口径说明**：地图学段分色为**本小程序 UI 自定**（小学蓝 `#2F5CD6` / 初中橙 `#E8850C` / 高中绿 `#0F9D58`），**不沿用项目老代码 `STAGE_COLOR`（紫/红/绿）**；项目代码配色仅作历史参考，已被本 UI 稿取代。学段**取值**（数据字段）严格以项目结构表为准（见各屏「数据字段引用」）。

## 全局需求（跨页面）

- **小程序名称**：广州学途。
- **运行形态**：微信小程序；右上角系统胶囊（··· 更多 / ⊕ 退出小程序）为微信原生元素，常驻所有页面（地图层、搜索页、详情页、异常态），不可自定义。
- **底部导航**：原生 tabBar，两项 —— 首页 / 学校；当前项高亮。
- **视觉基调**：主题色知性蓝 #2F5CD6；五类标签色（行政区 / 学段 / 示范等级 / 办学性质 / 招生方式）按原型表建立。
- **标签展示规则（全局）**：① 行政区标签**固定为全名并带「区」字**（如「荔湾区」「越秀区」），不省略「区」；② 同一学校若含**多个学段**，按学段**拆成多枚独立学段标签并排展示**（如「小学」「初中」），**不合并写成一枚「初中/高中」**（适用于联想词条、集团成员行等列表场景）；③ 同一类别多个取值一律拆成多枚标签，不合并进一枚；④ **详情卡例外**：多学段学校的详情卡（半窗 / 全屏）头部「学段」标签**只展示当前选中 tab 对应的学段**（tab 条本身罗列该校全部学段，见 06C / 07B）。
- **招生方式标签（全局通用）**：招生方式机制标签，**无独立样式、并入通用标签体系**（方角 Tag，中标签档：高 24 / r=6 / 12px，不加描边；「招生方式」类＝知性蓝浅调：底 #F2F6FE / 字 #254BAE；UI 图见 UI 稿第 01 节「通用 · 标签样式（Tag）」与「通用 · 招生方式标签」）；初中详情卡「招生计划（2026年）」中**随每条「招生方式」逐条展示**（不再是模块标题右侧单枚标签，见 07B），文案取真源 `middleEnrollmentMechanisms` label、共 **7 种**，随该学段招生方式切换：**单校划片 / 对口直升 / 多校电脑派位 / 电脑派位 / 电脑抽签 / 自主招生 / 2026 无招生计划**（与 `mechanism` 枚举映射见 07B）。
- **筛选栏胶囊规则（全局）**：筛选栏三个维度胶囊（区域 / 学段 / 办学性质）**多选维度显示维度名、单选维度显示选中内容**——「区域」单选后显示所选项（行政区显示**带「区」字全名**如「荔湾区」；地铁显示**站名**或「地铁·N 站」），学段 / 办学性质（多选）固定显示维度名；所有胶囊**不显示任何已选数量角标或数字**；「区域」胶囊展开为**三列下钻面板**（见 04），「学段」「办学性质」仍为选项组切换（见 05 / 06）。
- **地图默认视野**：广州中心城区中轴线（珠江新城 — 广州塔一带）。
- **定位授权（本次接入）**：用户进入首页后底部弹出**定位授权引导弹窗**（UI 稿 01B，文案见 01B）；点「开启定位」→ 触发微信系统位置授权（`wx.getLocation`），允许后地图自动移动到定位点附近并显示当前位置标记；拒绝或失败 → 保持默认中心城区视野，不影响其他功能使用；引导弹窗每次冷启动最多提示 1 次，点「暂不开启」后本次会话不再弹出；**系统授权点「不允许」后记录拒绝日期，30 个自然天内不再自动弹出，超过 30 天后的首次冷启动可再自动提示一次**。
- **表单（表格）统一规范（跨页面通用）**：适用范围＝07B 中考报考情况（录取明细表）、07E 第一批招生（分项目表）／第二批招生（覆盖初中表）；12B / 12C 学校页表格同属此规范，实现时按同一套列定义落地。
  - ① **表头与数据行共用同一套网格列定义**，只按列数切换变体，不换对齐方式；**表头文字与其下方数据同向对齐**——数值列（名额 / 录取最低分 / 计划人数等）的**表头与数值一律右对齐**，避免「表头左对齐、数值右对齐」看起来像两列（`thead` / `trow` 同用一个网格类，数值列在表头与数据行都带同一对齐类）。
  - ② **窄列只给够用宽度**（约「表头字数 × 字号」，含列间距）：统一换算为 375 画布下的宽度——三列「校名 ｜ 所在区 ｜ 名额」＝`minmax(0,1fr) 46px 40px`；两列「校名 ｜ 名额」＝`minmax(0,1fr) 40px`；三列「高中 ｜ 名额 ｜ 录取最低分」＝`minmax(0,1fr) 40px 70px`。**余下宽度全部让给第一列**（所在区 / 名额 / 录取最低分不占多余空间），窄列内数值紧随表头、不留空列。
  - ③ **第一列校名尽可能占宽**、单行展示（不换行成 2 行），**最大显示宽度＝该列剩余宽度**（即屏幕宽 − 窄列宽 − 内边距），超出用「…」截断（CSS ellipsis）；点进该校详情卡后可见全名。
  - ④ **分组行（关联校区 / 生源小学 / 共享计划校区等）**：**学段标签、「当前查看」胶囊紧跟校名、不右对齐**（行内固定间距，校名与标签之间不留弹性空白）；校名**按实际字数展示**，只有**标签多（如 学段 + 学段 + 「当前查看」）或校名过长**时才收缩、单行「…」截断——标签越长，左侧校名允许显示的字数越少（如「广州市白云区星悦实验学校（初中部）」+「初中」标签 → 校名截断为一行）；标签本身**先占位**（不压缩、不换行）。
  - ⑤ **字段行（字段名 + 填充值）**：左字段名**定宽 130px**（375 画布；宽度须容纳最长字段名「省市属高中录取名额」9 字，否则单行不换行会溢出、把间距吃掉，看起来「字段名与值贴在一起」）、右侧填充值，两者间距约 24px。同一模块内多行字段值**靠同一列起排**（如第二批次「名额考生数／省市属高中录取名额／区属高中录取名额」三行）。
- **画布基准**：手机框 375 × 812。

## 01 首页（地图层）

1. 首页以整屏真实地图为背景，按真实地理位置预置学校点位。
2. 提供悬浮搜索框入口，占位「搜索广州小初高学校」；点击进入搜索页。
3. 筛选栏提供三个维度入口：区域 / 学段 / 办学性质；点击**两步位移展开**对应维度的筛选面板（「区域」见 04 三列下钻，「学段」「办学性质」见 05 / 06）。三胶囊**多选维度显示维度名、单选显示选中内容，不显示已选数量角标或数字**（见「全局需求·筛选栏胶囊规则」）。
4. 左下角图例区说明点位三色含义：小学 / 初中 / 高中（具体颜色见「数据字段引用」）；**图例另含「多学段」条目**（见第 9 条）。
5. 底部导航两项（首页 / 学校），点击切换、当前项高亮。
6. 地图支持双指缩放、单指拖动。
7. 点击学校点位 → 底部弹出半窗学校卡（默认约 45% 屏高，约 365px／812 屏），该点位进入选中态。
8. 页面默认按广州中心城区中轴线视野展示；首次进入先弹出定位授权引导弹窗（见 01B），允许授权后地图自动切换到定位点附近并显示当前位置标记，拒绝则保持默认视野。
9. **多学段点位（需求层）**：同一学校实体可能同时含多个学段（如九年一贯制含小学 + 初中、十二年一贯制含小学 + 初中 + 高中）。地图将点位按 `school_id` 或同址坐标合并为**一个多学段点位**，图例须新增「多学段」分类条目；多学段点位以"所含各学段色拼合"区分（具体视觉拼合方式见 UI 稿 06 帧规范）。

**数据字段引用（本屏展示所用）**

- **学段判定**：`data/registry/entities.json` → `entities[].stage`（类型 `SchoolStage = 'primary' | 'middle' | 'high'`）。
  - 取值示例：小学 → `'primary'`（示例实体 `school_id=gz-440105-9aac697e`，名称"万松园小学(云桂校区)"）；初中 → `'middle'`（示例 `school_id=gz-440103-53cac770`，"广东实验中学荔湾学校(初中部)"）；高中 → `'high'`（示例 `school_id=gz-440103-3aca532e`，"广东实验中学(高中部)"）。
- **学段标签（展示文案，真实映射）**：`packages/shared/src/domain/map/constants.ts` → `STAGE_LABEL = { primary:'小学', middle:'初中', high:'高中' }`（用于详情卡学段标签 / 联想词条标签）。
- **学段配色（视觉，UI 自定）**：本小程序 UI 指定为 小学蓝 `#2F5CD6` / 初中橙 `#E8850C` / 高中绿 `#0F9D58`（见 UI 稿图例与规范表）；**不沿用项目老代码 `STAGE_COLOR` 的紫/红/绿**。
- **点位坐标与落位**：`data/{primary,middle,high}/schools-gz.json` → `{ ..., schools: [...] }`，每条含 `name, lng, lat, adcode, school_id`（高中文件另含 `school`）；点位合并后运行时结构 `MapPoint`（`packages/shared/src/domain/map/filters.ts`，由 `points.ts` 的 `buildPoints` 生成），其 `stages: SchoolStage[]` 记录该点位所含学段（单学段长度 1，多学段长度 2–3）。
  - 多学段真实示例：`school_id=gz-440113-000bd12e`，名称"万翔学校"，`stages=['primary','middle']`（小学 + 初中，九年一贯制）→ 地图上该点位由小学色(蓝 `#2F5CD6`) + 初中色(橙 `#E8850C`) 拼合显示（各半圆）。全库共 183 个 school_id 跨多学段；含高中的多学段示例：广州市第五中学（初中＋高中，`gz-440105-0ffca7e3`）、祈福英语实验学校（小学＋初中＋高中，`gz-440113-c181d193`）。
- **行政区归属**：`schools-gz.json` 的 `schools[].adcode` → `constants.ts DISTRICTS`（七区 `adcode`/`name`/`color`，如荔湾 `440103`、越秀 `440104`、海珠 `440105`、天河 `440106`、白云 `440111`、黄埔 `440112`、番禺 `440113`）；`districtByAdcode` 提供 adcode → 区名映射。

## 01B 首页 · 定位授权引导弹窗

1. 触发：进入首页后（当前未授予位置权限时）自动底部弹出引导弹窗（底部半窗样式：蒙层 + 圆角面板、无拖拽 handle，见 UI 稿 01B）；每次冷启动最多自动提示 1 次。
2. 弹窗文案（已确认）：
   - **标题**：开启定位，找附近的学校
   - **正文**：开启后，地图会自动移动到你附近，并按距离展示周边学校。位置信息仅用于本校小程序内的地图定位与筛选，不会存储或对外分享。
   - **主按钮**：开启定位；**次按钮**：暂不开启。
   - **底部小字**：可在微信「设置－位置信息」中随时更改授权。
3. 点「开启定位」→ 触发微信系统位置授权（`wx.getLocation`）：允许 → 地图自动缩放到「当前定位点 + 最近的一所可见学校」都能框入的视野，**保证定位后周围至少能看到一个学校点位（而非聚焦过近导致四周无学校）**；缩放上限约 `scale 14`（≈1.3km 兜底跨度，即使用户与最近学校几乎重合也保留该范围），并显示当前位置标记；拒绝（点「不允许」）→ 轻提示后关闭弹窗，保持默认视野；**记录拒绝日期，此后 30 个自然天内不再自动弹出，超过 30 天后的首次冷启动可再自动提示一次**。
4. 点「暂不开启」或弹窗外空白区域 → 关闭弹窗、保持默认视野；本次会话内不再自动弹出。
5. 授权状态可随时在微信「设置－位置信息」中更改；更改后下次进入按新状态执行本流程。

**数据字段引用（本屏展示所用）**：定位为端上能力（`wx.getLocation` 返回经纬度），无数据表字段。

**实现与合规口径** ⚠️：需在 `app.json` 声明 `permission["scope.userLocation"].desc` 与 `requiredPrivateInfos: ["getLocation"]`，并在小程序管理后台《用户隐私保护指引》中声明收集位置信息的目的、方式与范围；接口可用性还受小程序类目与平台审核口径影响——**以微信公众平台最新文档为准（开发前需核对官方文档）**。

## 02 搜索页 · 默认态

1. 入口：点击首页搜索框弹出本页。
2. 页面组成：搜索栏 + 历史记录区 + 推荐搜索区 + 键盘区。
3. 搜索栏：含返回按钮、默认占位词「支持广州小初高学校搜索」；搜索栏头行与微信原生胶囊（··· / ⊕）**顶部对齐、同行同高**（头行高 44px、搜索框 32px 行内垂直居中），对齐实现口径见 UI 稿「小程序胶囊」规范表。
4. 搜索按钮：无输入时不展示；有输入内容后才出现并可点击。
5. 历史记录区：仅在存在历史词条时展示，按搜索时间倒序，以胶囊平铺自动换行呈现；右侧「清空」触发二次确认弹窗（见 11）。
6. 推荐搜索区：展示省市属高中，按拼音首字母排序（排名不分先后）。
7. 进入页面自动唤起键盘。
8. 返回：点击返回按钮或左滑手势回到来源页（默认首页）；从筛选面板展开态点击搜索框进入时，返回直接回首页且面板保持收起。
9. 执行搜索：
   - 有结果 → 关闭搜索页回到首页，地图定位到结果学校、点位选中并自动拉起详情卡半窗（见 06B）。
   - 无结果 → 进入异常态 A（见 08）。

**数据字段引用（本屏展示所用）**

- **推荐搜索（省市属高中）**：`data/high/levels.json` → `{ schools: [...] }`，每条含 `name, district, category('普通高中'|'省市属示范'|'区属示范'), campuses, aliases`（另含 `affiliation, demo, indicators`）；按 `name` 拼音首字母排序展示（排名不分先后）。
- **历史记录**：端上本地缓存（非服务端数据表），按搜索时间倒序；仅存在时展示。

## 03 搜索页 · 联想词态

1. 输入即联想，支持三种匹配：精确 / 模糊 / 别名；优先展示精确匹配，无精确结果时展示模糊匹配。
2. 排序规则：模糊结果按关联度排序；关联度相同按行政区（荔湾 > 越秀 > 海珠 > 天河 > 白云 > 黄埔 > 番禺）；行政区相同按学段（小学 > 初中 > 高中）。
3. 词条右侧显示学校标签：行政区、学段。行政区标签**固定为全名并带「区」字**（如「荔湾区」）；若该学校含**多个学段**，按学段**拆成多枚独立学段标签并排**（如「小学」「初中」），**不合并写成一枚「初中/高中」**。
4. 联想词条区铺满全页，词条过多时支持上下滑动。
5. 执行搜索：点击「搜索」按钮或任一联想词条 → 执行搜索（结果处理同 02 第 9 条）。

**数据字段引用（本屏展示所用）**

- **联想匹配源**：`data/registry/entities.json` → `entities[].name` / `entities[].aliases`（精确 / 模糊 / 别名三种匹配），命中后取 `stage` 作为学段标签、`school_id` 作为跳转键。
- **排序依据**：关联度（模糊匹配 score）→ 行政区序（`DISTRICTS` 顺序：荔湾 > 越秀 > 海珠 > 天河 > 白云 > 黄埔 > 番禺）→ 学段序（`STAGE_PRIORITY`：小学 > 初中 > 高中，即 primary < middle < high）。
- **词条右侧标签**：行政区 `districtByAdcode[adcode]`（**全名带「区」字**） + 学段 `STAGE_LABEL[stage]`；多学段学校 `stages: SchoolStage[]`（长度 2–3）**逐学段拆成多枚标签**，不合并为一枚。

## 04 筛选面板 · 区域分类（行政区/板块 · 地铁）

1. 入口：点击筛选栏「区域」胶囊 → **分两步展开顶部通栏白色筛选面板**：**第一步**，搜索框与筛选栏整体上移（**搜索框移至与右上角胶囊同一行**）；**第二步**，筛选面板自所点维度胶囊处**由上向下推出**，展开为顶部通栏白色面板——其下依次为筛选栏、三列下钻选项区，搜索框、筛选栏、筛选项**同属一个白色窗口**；**面板下方地图覆盖灰色蒙层**。**「区域」不再以扁平选项组呈现，而是改为三列下钻面板**。**区域维度为单选，面板底部无「全不选 / 确认」按钮**（选中即应用，见第 3、4 条）。
   - **面板头部并非另起一个覆盖弹层，而是首页原顶部悬浮栏（搜索框 + 三枚筛选胶囊）整体上移位移而成**；展开态各段对齐与间距硬约束（实现口径，见 UI 稿 04 帧规范）：① 搜索框右缘**对齐右上角胶囊左缘**（右留白 = 屏宽 − 胶囊左缘 + 4px）；② 三枚筛选胶囊**等宽（`flex:1`）且横向间距 8px（16rpx）**；③ 搜索框／筛选栏／选项区**左缘统一内缩 28rpx**；④ 搜索框→筛选栏→选项区**三段纵向间距统一 16rpx**；⑤ 三列下钻区**等宽三列、列间 1px 分隔线**、整块高度约 236–260px（**与「学段」筛选窗口等高、不随列内条目增多而变高**）、三列各自纵向滚动。

3. **区域维度为单选（三列下钻同一时刻仅一条 drill 路径呈选中态）**。**选中态视觉＝仅文字变蓝（#254BAE）加粗、无底色块**；三列对应单元格文字同时变蓝，「全部 xx 区」行**无圆点等任何前缀标记**（视觉口径见 UI 稿 04）。弹窗拉起时**默认不预勾选任何独立选项、也不按当前地图区域把按钮置为选中**——仅按【当前已生效区域】高亮对应行：当前展示某区则（维度＋该区＋全部该区）**整行高亮、其余均不选中**；当前展示全城（未限定区域）则**无任何行高亮**。各列点选规则：① **点第一列切换维度**（行政区/板块 ↔ 地铁）时二三列整体替换、并高亮该维度当前已选路径；② **点第二列某区/某线** → 高亮该行（行政区维度同时高亮「全部 xx 区」、地铁维度高亮该线已选站/首站），其余一级项取消高亮（**面板保持展开**）；③ **点第三列某二级项** → **弹窗立即关闭并即时生效（无「确认」步骤）**；其中**板块 / 地铁站为「仅定位、不过滤」**（见第 6 条），**只有行政区（含「全部 xx 区」）才执行点位过滤**。「全不选」已取消。
4. **区域维度面板无「全不选」「确认」按钮，底部仅一枚整行右对齐的「重置」按钮**（仅区域维度有）。**「重置」**＝把区域维度恢复为默认不限区域态（展示全部学校＝全城），清空板块/地铁选择并关闭面板，不影响学段/办学性质筛选。**应用时机＝点第三列二级项即时生效并关闭面板**；**点面板下方灰色蒙层或维度胶囊以外的收起操作** → 面板收起、**不应用**、还原到展开前已生效的区域（不保存本次浏览的临时高亮）。
5. 面板展开期间顶部搜索框保持可见；点击搜索框 → 收起面板并跳转搜索页；此时搜索页点返回 → 直接回首页，面板保持收起。
6. **【核心口径】行政区过滤，板块/地铁仅定位**：
   - **只有行政区维度执行点位过滤**：选「全部 xx 区」＝只保留该区学校（按 `adcode` 剔除区外点位），并把视野缩放到该区全部点位的外接矩形（安全边距不扩大到未选区）。
   - **板块 / 地铁站不做任何点位过滤**：点第三列具体板块/站点后，**地图只把相机切到该选项及其邻域，学校点位仍全量展示（七区全部点位都在）**，不再按 `plateId` 单值映射或站点半径剔除学校——避免吞掉板块交界/站点周边本该可见的学校。
     · 定位视野（2026-10-16 收紧，原「固定半径 + 大包围盒」会让一屏跨 5~6km、看不出定位在哪）：**板块按「该板块归属学校的实际范围」定框**（剔除离群 15% 后取外接矩形、再外扩约 12%，避免个别远校把视野撑爆）；**地铁站取站点周边 0.8km 方框**。相机再按「视口 − 边距」反推包围盒，使**一屏可视宽度夹在 1.3~2.8km**（竖屏约 1.7~2.8km 宽 × 3.5~5.8km 高，街区级尺度），既看得出定位落在所选板块，也不会把邻区（如荔湾选板块却框进海珠）一并显示。
     · 学段 / 办学性质属属性维度、不移动相机；筛选结果为 0 时不移动（转异常态 C 见 10）。
7. **同一屏幕只允许一个操作窗口**：筛选面板与学校详情卡互斥——学校卡正打开时点击「区域」胶囊，先自动关闭学校卡、再展开面板；反之面板展开时点学校点位先收起面板再挂卡（搜索页同理）。

## 08 异常态 A · 搜索无结果

1. 触发：精确 + 模糊 + 别名三种匹配均无结果时，联想词条区替换为空状态。
2. 空状态四要素：插画 + 标题 + 说明 + 主操作。
3. 主操作「清空并重新搜索」：清空输入词并重置全部筛选条件，回到搜索页默认态。
4. 空状态下不展示历史记录区 / 推荐搜索区，避免与空态信息互相干扰。

**数据字段引用（本屏展示所用）**：本态为端上空状态展示，无服务端数据字段读取（匹配判定依赖 03 的 `entities` 联想源，详见 03）。

## 09 异常态 B · 网络加载失败

1. 触发：详情 / 列表接口超时或返回失败时，内容区替换为加载失败态；顶部导航保持可用。
2. 主操作「重新加载」：局部重试，仅重新请求失败的模块，不整页刷新。
3. 连续 2 次重试仍失败 → 按钮下方追加「反馈问题」文字入口。
4. 加载中状态：请求期间该模块展示骨架屏；超过 10s 未返回自动转为本态。

**数据字段引用（本屏展示所用）**：重试请求的是各模块对应数据接口（模块与字段对照见 07「数据字段引用」）；局部重试仅重拉失败模块。

## 10 异常态 C · 筛选结果为空

1. 触发：筛选条件组合在当前地图视野内无匹配点位时，地图中央弹出异常提示弹窗（样式走全局弹窗统一规格，宽 240px）。
2. 地图场景弹窗不加遮罩，缩放 / 拖动手势仍可用，用户可先调整视野再决定是否重置。
3. 关闭：弹窗右上角提供「×」关闭按钮，点「×」仅关闭弹窗、保留当前筛选；主操作「重置筛选」恢复全部维度默认全选并关闭弹窗。
4. 同一规则适用于首页地图层；搜索结果页如遇同类情况，复用异常态 A 的空状态。

**数据字段引用（本屏展示所用）**：筛选匹配依赖 `entities[].stage` / `entities[].nature` 与 `DISTRICTS` 枚举（见 01 / 05）；本态本身无新增字段。

## 11 通用弹窗 · 清空历史确认

1. 触发：搜索页点「清空」弹出本弹窗。
2. 复用原则：后续所有破坏性 / 不可逆操作（清空历史、重置全部筛选等）统一复用本对话框样式，不再各自定义。
