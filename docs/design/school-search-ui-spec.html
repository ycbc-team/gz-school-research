UI Spec · Mini Program · 知性蓝

广州小初高学校搜索
知性蓝 主题 UI 稿

依据原型画板《交互原型》绘制的高保真 UI 稿。按钮与交互按微信小程序习惯重做； 主题色由 知性蓝 #2F5CD6 延展，标签体系按原型表建立 四类标签色（行政区／学段／示范等级／办学性质）。

画框 375 × 812纯 HTML / CSS无脚本依赖主题色 #2F5CD6标签四类色
本文档为 UI/UE 设计规范，描述界面视觉、交互、组件、动效与状态；对应的产品功能需求（功能、业务规则、用户场景）见同级文件 school-search-prd.md。
本轮范围：共 7 屏 ＋ 异常状态 3 态（08–10）＋ 通用弹窗（11） —— 首页（地图层）／搜索页（默认态）／搜索页（联想词态）／筛选栏半窗（选中「行政区」）／筛选栏半窗（切换「学段」）／地图层／学校详情卡（小学）。 其中首页与地图层均为「整张地图铺满全屏 + 顶部小程序名行（白底常驻盖地图）／搜索框／筛选栏／图例区悬浮 + 底部导航栏置底」的同一套结构；地图背景取自育才中学（东校区）周边真实地图（示意），点位按真实相对位置落位，产品默认视野为广州中心城区中轴线（珠江新城—广州塔一带）。 均按原型稿中实际出现的元素绘制。其余页面（学校详情长图·初中／高中、品牌关联·多学段 tab 页、政策 tab 等）待指定后再出。

通用 · 标签样式（Tag）

标签只承担「信息归类」，不做交互。类别按原型表取 4 类：行政区／学段／示范等级／办学性质，一类一个色相 —— 底色取该色相的浅调、文字取同色相深调，不加描边、不加投影； 同一类别内的不同取值共用该类颜色，若需再区分只允许在同色相内升降一档，不跨色相。 尺寸是两档、独立于类别的第二维度：小标签 高 19 ／ r=5 ／ 10.5px（列表词条右侧）；中标签 高 24 ／ r=6 ／ 12px（学校卡、详情信息行）。下面「尺寸档」两行即同一组 4 类取值分别套用两档尺寸，颜色不变。

产品功能需求详见 school-search-prd.md ·「03 搜索页 · 联想词态」

交互描述

1）输入即联想：支持精确、模糊、别名三种搜索；优先展示精确匹配，无精确结果时展示模糊匹配。
2）排序规则：模糊结果按关联度排序；同关联度按行政区排序（荔湾>越秀>海珠>天河>白云>黄埔>番禺）；同行政区按学段（小学>初中>高中）。
3）词条右侧展示学校标签（行政区、学段）。
4）词条区直接盖在页面上、铺满全页，词条多时支持上下滑动。
5）搜索按钮：无输入不展示；开始输入后流畅出现（淡入 + 左移约 180ms、搜索框同步变窄约 220ms），知性蓝可点；点击搜索按钮或任一词条 → 执行搜索。

对应原型 · 地图层交互说明

· 地图层是一整张地图背景，铺满全屏（含状态栏区域）。本稿底图为真实地图示意（OpenStreetMap 越秀区局部，约 1.65 × 3.58 km，示意中心取育才中学（东校区）水均南街一带）；产品实际默认视野为广州中心城区中轴线（珠江新城—广州塔一带），并非固定展示本稿示例区域。
· 点位为真实学校按实际位置落点：小学 4（东风东路小学本部／越秀区育才学校／东风东锦城校区／铁一小学）、初中 1（东风实验学校）、高中 4（育才东／西校区、铁一中学、培正中学）。
· 搜索框与筛选栏为悬浮层，浮在地图之上：白底 96% 透明 + 投影，不占页面版式。
· 左下角为学校类型图例（小学蓝／初中橙／高中绿／多学段）；同一学校实体含多个学段时合并为一个多学段点位，按所含学段以扇形拼圆：小学+初中=蓝橙各半圆，小学+初中+高中=三色各 1/3 圆（圆心同点）。点击具体学校，底部展示学校详情卡，选中点位放大高亮并弹名称气泡。
· 半窗学校卡（卡体总高约 206px，即 812 屏的 25%）：右上 ✕ 关闭、校名 + 行政区／学段／办学性质三标签；下方直接复用详情长图内容，按半窗高度自动截取可视部分（顶部模块，如「学校信号」），底部渐隐遮罩；「展开详情」胶囊叠于渐隐区之上（右下角，不单独占行）；点击／上滑即展开为全屏长图（07 屏）。
· 详情卡为最上层：整层盖住底部区域，底部导航 tab 被遮挡在卡片之下（收起卡片后才露出）。

交互描述

1）默认显示范围：按广州中心城区中轴线（珠江新城—广州塔一带）视野定位展示（后续版本增加定位授权弹窗；本稿底图为示意区域）。
2）地图交互：左下角有学校类型图例；支持手势放大、缩小，跟随手指滑动移动地图。
3）点击学校点位 → 底部弹出半窗学校卡（默认 25% 高，内容为详情长图按高度自动截取），选中点位 UI 呈选中态；点击其他点位切换卡片。
4）半窗 ↔ 全屏：卡片内上滑／点右下角「展开详情」／点击卡片内容 → 页面上滑展开为全屏详情长图（07）；全屏页往下滑或点返回 → 收起回半窗卡（25% 高）；点 ✕ 或半窗卡以外区域 → 关闭卡片。
5）搜索框／筛选栏为悬浮层，交互同首页。

搜索执行后 · 回到首页定位态（视觉规范）

· 结果学校点位呈选中态：放大高亮 + 名称气泡（视觉同 06 点选点位）。

· 详情卡内其他学校名为可点击链接样式（知性蓝 + ›）；点击当前学校触发 toast——屏幕居中偏下半透明黑底白字圆角胶囊，约 1.5s 自动淡出，不阻断操作、不加遮罩。
· 过渡动效：地图自动定位缩放 → 点位高亮 → 半窗卡淡入上滑。
