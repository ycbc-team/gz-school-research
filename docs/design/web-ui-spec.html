UI Spec · Web Responsive · 知性蓝

广州学途 · Web 端 响应式 UI 稿

依据小程序 UI 稿 school-search-ui-spec.html 与 PRD 对齐改写： 保留全部产品逻辑、配色、标签与表格规范；将小程序专有交互（原生胶囊 / tabBar / 半窗手势 / wx.getLocation）转换为等价的 Web 响应式交互。 本稿为纯静态 HTML/CSS，手机浏览器可直开，是后续 Web 开发的视觉与交互基准。

桌面 ≥1024 · 平板 768–1023 · 手机 <768 纯 HTML / CSS · 无脚本依赖 主题色 #2F5CD6 框架 = 小程序两 Tab：首页 / 学校 桌面侧栏 + 移动底 Tab 小程序 01–12C-B 共 28 屏逐屏对应 · 桌面 / 手机双版本
框架对齐小程序（重要）： 整个 Web 的信息架构与小程序一致——全局导航只有 两个 Tab：首页、学校（小程序原生 tabBar 的两项）。 桌面端用「左侧固定导航（首页 / 学校）」表达，移动端用「底部 Tab（首页 / 学校）」表达；不再设集团关联 / 荣誉榜 / 小学·初中·高中明细等独立导航项。 小学 / 初中 / 高中是「学校」Tab 内的学段分段控件，不是独立页面。
交互差异处理： ① 定位：wx.getLocation + 30 天静默 → Web Geolocation，直接触发浏览器/系统原生权限弹窗（页面不自绘授权 UI）+ 会话内不再自动触发（sessionStorage）；入口在地图右下角悬浮按钮； ② 学校卡：半窗手势展开 → 桌面右侧抽屉 / 移动底部抽屉 → 点「展开详情」进路由详情页； ③ 筛选：顶部通栏半窗 → 桌面弹层 / 移动底部抽屉（三列下钻不变）； ④ 搜索：独立搜索页 → 顶部搜索 + 联想下拉 / 移动搜索覆盖层。 业务规则、数据字段、学段分色、标签与表格规范原样保留。
怎么看这份稿子：每屏标题右侧都有 「放大查看」 按钮，点一下即全屏按 1:1 设计尺寸展示该屏（手机上字小就靠它）；再点右上角 「关闭」 返回。纯 CSS 实现、不依赖脚本，手机浏览器直接打开也能用。

通用 · 标签样式（Tag）

标签只承担「信息归类」，不做交互。类别取 5 类：行政区／学段／示范等级／办学性质／招生方式（招生方式为后续新增字段，直接并入本体系、不另立组件），一类一个色相 —— 底色取该色相的浅调、文字取同色相深调，不加描边、不加投影；同一类别内的不同取值共用该类颜色，若需再区分只允许在同色相内升降一档，不跨色相。 尺寸是两档、独立于类别的第二维度：小标签 高 19 ／ r=5 ／ 10.5px（列表词条右侧）；中标签 高 24 ／ r=6 ／ 12px（学校卡、详情信息行）。下面「尺寸档」两行即同一组 4 类取值分别套用两档尺寸，颜色不变。
