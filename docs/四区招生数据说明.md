## 二、构建流程

```bash
python3 scripts/build_district_enrollment.py all
# 或单区：python3 scripts/build_district_enrollment.py liwan
```

统一脚本 `scripts/build_district_enrollment.py` 复用番禺试点（旧 `scripts/build_panyu_enrollment.py` 保留作回归锚点）的分层匹配逻辑，并按本区经验迭代：

- **映射表优先**：官方校名命中 `NAME_MAP` 时直接绑定对应 POI（1100 分），覆盖托管/集团更名、别名、校区名差异等通用规则覆盖不到的案例。映射表是**人工维护的显式清单**，逐条带依据注释（见脚本 `NAME_MAP`）。
- **通用规则**（映射表之外）：校区互斥（官方校区名↔POI 校区名，`same_campus` 允许互相包含）、1000 全名 / 950-900 前缀 strip / 900 去括号 / 850 词尾等价 / 750 校区-校区核心 / 600+ 互相包含 / 500+ 核心包含 / 450+ 词尾等价包含；包含类均带 `is_generic`（泛称后缀禁包含）与 `ratio_ok`（短侧≥长侧 60%）防护；教育集团前缀（华阳教育集团/体育东路教育集团/广州华阳集团/广东番禺中学教育集团等）纳入 `PREFIXES` 统一剥离。
- 过滤泛名/在建类 POI（"学校"、"建设中"、"工地"等）；全区 POI 按匹配分全局贪心分配，同一 POI 被多条记录竞争时记为歧义。

## 六、数据口径与已知误差

1. **海珠**：地段表为官网图片 OCR 转录，个别校名/社区名可能存在错字，**以官网原图为准**；班数缺失（计划表附件未抓）。
2. **天河**：附件5 为扫描 PDF OCR 转录，个别楼号/号段可能有简并，**以官方 PDF 原文件为准**；已修正"新元小学"等 OCR 误读。
3. **荔湾**：地段按"街道·社区：路街巷"拼接；附件1 计划表 47 所与附件4 地段表 493 行一一合并。
4. **越秀**：登记范围为"行政街+路段"原样文本；班数来自块尾"说明"。
5. **性质字段**：番禺含公办（地段）+ 民办（电脑派位）；四区均为公办（`nature: "公办"`）。
6. **歧义记录**：仅记录共享 POI 的竞争关系，胜者已绑定，败者在未匹配名单中。
