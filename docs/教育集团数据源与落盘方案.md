# 教育集团齐全化：数据源与落盘方案

> 目标：让「教育集团名录 + 集团下所有成员校」在数据层齐全、可追溯、可持续更新。
> 结论先行：**广州没有官方教育开放 API**；最接近「API 级」的结构化官方数据是
> 广州市招考办**每年发布的集团直接名额分配表**（已落盘见 `data/registry/education_groups_2026.json`），
> 其余集团关系须以「官方文件 + 集团官网 + 区级名单」交叉核实落盘。

---

## 一、数据源盘点（按可机器化程度排序）

### L1 · 可机器抓取的结构化官方数据 ✅（已落盘）
| 来源 | 内容 | 更新节奏 | 覆盖 |
|---|---|---|---|
| 广州市招考办「示范性普通高中面向集团的直接名额分配情况」<br>`gzzk.gz.gov.cn`（2026 版：post_10809470） | 集团核心校 → 集团内初中成员（含农村初中标记） | 每年 5 月 | **43 个集团核心校 / 118 条成员关系**（省市属 7 + 区属 36） |
| 高德 POI API（现有数据管道） | 全部学校点位（坐标/区码/名称） | 手动补录 | 930+ 小学 / 475 初中 / 126 高中 |

### L2 · 官方文件（半结构化，需逐篇解析）
| 来源 | 内容 | 例子 |
|---|---|---|
| 广州市教育局 `jyj.gz.gov.cn` | 集团化办学总结/总量（2025 底全市 **242 个集团**，155 个含义务教育段） | post_10572448、post_10220448 |
| 广州市政府门户 `gz.gov.cn` 各区频道 | 各区集团名录 + 成员校清单 | 天河 8 集团/45 校、黄埔 13 集团/60 校、越秀「669」（6 集团）、海珠 11 集团/74 校、从化 4 集团 |
| 广东省教育厅 | 省优质集团名单（广州 48 培育对象、20 个第一批省优质） | — |
| 集团官网 | 集团成员列表 | 广铁一中 `gtyz.edu.cn`、广附 `gdfz.edu.cn`、广雅/执信官网 |

### L3 · 商业/查询 API（非教育专属，成本高）
- 天眼查/企查查：可核学校法人、统一社会信用代码、举办单位（本项目已用于 tier1 法人核验）；
  不适合批量拉集团关系（付费 + 非官方口径）。
- 无任何「教育集团」维度的开放 API。

## 二、落盘 Schema（建议）

```jsonc
// data/registry/education_groups.json（全量版，替代单年快照）
{
  "title": "广州教育集团名录",
  "updated": "2026-09-10",
  "groups": [
    {
      "brand": "广铁一中教育集团",          // 集团名（对外品牌）
      "core": ["广州市铁一中学（越秀校区）"],  // 核心校（可多所）
      "level": "省市属|区属",
      "members": [
        { "name": "广州市黄埔区铁英学校", "relation": "成员校|托管|校区|分校",
          "legal": "独立法人|同法人", "source_url": "…", "verified": "2026-09-10" }
      ],
      "source_urls": ["…"]
    }
  ]
}
```

与现有数据的关系（**三层各司其职**）：
- `tier1_schools_all.json`：口碑/挂牌判定（成绩本位），只收录第一梯队证据校；
- `brand_groups.json`：**用户核心关注品牌**（当前 8 组）的详情页「品牌关联」板块；
- `education_groups.json`（新增）：全量集团 + 成员校的 registry，供品牌板块扩展与覆盖核对。

## 三、分阶段执行建议

| 阶段 | 内容 | 方式 | 工作量 |
|---|---|---|---|
| **P0（已完成）** | 招考办 2026 表落盘 `education_groups_2026.json` | 解析官方表 | 1 轮 |
| **P1** | 43 个集团核心校补齐「集团名 + 核心校 POI 关联」，成员校全部比对现有 POI 三层覆盖 | 脚本 + L1 数据 | 1 轮脚本 |
| **P2** | 8 个重点品牌（现 brand_groups）按官方表/官网交叉核对成员完整性（如铁一组还应含美华/红岩/十甫？） | 官网 + 区文件 | 中 |
| **P3** | 区属非示范集团 + 小学集团（华阳、体育东、天府、东风东等）按各区文件补录 | **建议 OrganizeAgent 逐区核对**（同新校核对模式） | 大 |
| **P4** | 每年 5 月招考办新表发布后，跑一次更新脚本刷新成员关系 | 脚本 + 人工复核 | 低 |

## 四、已落盘数据（本次）

- `data/registry/education_groups_2026.json`：43 个集团核心校（省市属 7 + 区属 36）、118 条集团内初中成员关系，全部来自招考办 2026-05-12 官方表。
- 成员覆盖区：越秀/荔湾/海珠/天河/白云/黄埔/番禺/花都/南沙/增城/从化（11 区）。
- 局限说明：该表为「示范性高中 + 集团内初中」口径；小学段成员与区属非示范集团不在表内（见 P3）。
