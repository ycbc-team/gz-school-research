# 独立法人挂牌校识别方案

> 编制日期：2026-09-09 ｜ 适用范围：广州7区（越秀/荔湾/海珠/天河/白云/黄埔/番禺）第一梯队小学59所、初中53所，共112校
> 数据文件：`data/primary/tier1_schools_all.json`、`data/middle/tier1_schools_all.json`
> 配套脚本：`scripts/build_tier1_js.py`、`scripts/build_middle_tier1_js.py`

---

## 一、问题背景

广州第一梯队名校在集团化办学浪潮下产生了大量"校区""分校""附属学校""实验学校"。民间梯队名单往往将这些点位与本部混为一谈，但实际上它们的法人主体、师资调配、生源沉淀差异巨大：

- **新建校区前2-3届**：青年教师多、生源沉淀不足，差距较大；3-6年稳定后逐步收敛。
- **同法人一校多区**：整体差距可控，头部尖子生数量通常弱于本部，平均分差距相对小。
- **独立法人集团挂牌校**：与本部差距普遍更大，有的只是共享教研资源，本质是另一所学校。

本方案的核心目标：**在数据层区分独立法人挂牌校，使其不计入第一梯队**，为后续地图页过滤提供字段支撑（本轮HTML不动，字段先就位）。

## 二、三类别定义

| 类别 | entity_relation | 定义 | tier1_eligible | 典型特征 |
|---|---|---|---|---|
| **本部** | `本部` | 学校自身即品牌源头，独立法人但非挂牌。包括传统名校本部、省属高校附属学校（品牌源头即自身，如华附、中大附中、华师附小） | `true` | 校名即品牌，历史悠久，民间公认度高 |
| **同法人校区** | `同法人校区` | 与本部共享同一事业单位法人（统一社会信用代码相同），为同一法人下的不同校区 | `true` | 校名格式为"XX中学（XX校区）"，市属学校直接开办；人事/财务由本部统一管理 |
| **独立法人挂牌校** | `独立法人挂牌校` | 独立法人（信用代码与本部不同）+ 借用他校名校品牌/委托管理/合作办学，本质是另一所学校 | `false` | 校名含名校品牌但实为区属公办或民办；仅共享教研/品牌，法人独立 |
| **待核** | `待核` | 公开信息不足，无法判定法人关系 | `true`（暂定，待核后修正） | 信用代码查不到、集团身份模糊 |

### 关键概念区分

- **办学实力强 ≠ 可计入本部第一梯队**：独立法人挂牌校即使 conclusion="有支撑"（如金广附、白云省实、天省），`tier1_eligible` 仍为 `false`，理由=独立法人挂牌校。
- **独立法人但品牌源头即自身的名校本部**（如中大附中、华附、省实、华师附小）不属于挂牌，仍 `eligible=true`。
- **同法人校区 eligible**（可标注"头部弱于本部"），新建校区单独标记 `opened_year`。

## 三、判定决策树

```
开始
 │
 ├─ Q1: 学校是否借用其他名校品牌？（校名含名校名/委托管理/合作办学/集团成员非核心）
 │   ├─ 否 → 本部（eligible=true）
 │   └─ 是 → Q2
 │
 ├─ Q2: 与品牌源头学校是否同一统一社会信用代码？
 │   ├─ 是（同法人）→ 同法人校区（eligible=true）
 │   └─ 否（独立法人）→ 独立法人挂牌校（eligible=false）
 │
 └─ Q3: 信用代码无法获取？
     ├─ 有其他强证据（编办文件/教育局公告明确"校区"vs"独立建制"）→ 据证据判定
     └─ 无 → 待核（eligible暂定为true，标注数据缺口）
```

### 判定细则

1. **决定性判据：统一社会信用代码**
   - 同一代码 = 同法人（一校多区）
   - 不同代码 = 独立法人
   - 公办学校看事业单位法人登记（各级编办）
   - 民办学校看民办非企业单位登记 / 办学许可证

2. **民办学校判定**
   - 名称含"民办"或实际为民办的，几乎必为独立法人
   - 若同时借用名校品牌（如省实附中/天省、白云省实、云雅、星执、恒润、番外）→ 独立法人挂牌校
   - 若民办校品牌源头即自身（如祈福新邨学校）→ 独立法人本部（非挂牌），eligible=true

3. **民转公学校判定**
   - 2022年民转公的（育才实验、金广附、黄埔广附、二中苏元），转公后仍为独立事业单位法人（区属）
   - 若原品牌借自名校 → 仍属挂牌校（金广附、黄埔广附、二中苏元）
   - 若品牌自身即源头 → 不算挂牌（育才实验）

4. **公办委托管理/品牌挂靠**
   - 西关广雅（广雅委托管理）、省实荔湾（省实集团）、白云铁一（铁一集团区属校）、黄埔铁英（铁一集团区属校）、清华附中湾区（清华附中合作市属校）
   - 均为独立法人 + 借用品牌 → 挂牌校

5. **同法人真校区识别**
   - 名称格式为"XX中学（XX校区）"且为市属学校直接开办
   - 典型：执信（执信路/天河）、二中（应元/科学城）、广附（黄华路/大学城）、铁一（越秀/番禺）、华附（石牌/知识城）、省实永平、培英云城
   - 新建校区标注 `opened_year`

6. **小学阶段高校附属校区分**
   - 省属高校直属附属（华师附小）→ 本部，eligible=true
   - 区属公办 + 高校品牌合作（华师附中实验小学、华师附中番禺小学、华师附属大学城小学、广大附属小学）→ 独立法人挂牌校

## 四、证据源清单

| 证据源 | URL / 访问方式 | 可信度 | 适用场景 | 备注 |
|---|---|---|---|---|
| **全国组织机构统一社会信用代码公示查询平台** | https://www.cods.org.cn | ★★★★★ | 所有学校的信用代码、法人名称、法人类型查询 | 官方平台，数据最权威；部分事业单位可能未公示 |
| **广东省事业单位登记管理局公示** | http://www.gdbb.gov.cn（编办） | ★★★★★ | 公办学校事业单位法人登记信息 | 省编办官网，可查省属/市属事业单位 |
| **广州市事业单位登记管理局公示** | 广州市委编办官网 | ★★★★★ | 区属公办学校法人登记 | 各区编办公示 |
| **各区教育局民办学校年检公告** | 各区教育局官网（如 https://www.yuexiu.gov.cn/gzjg/qzf/qjyj/） | ★★★★☆ | 民办学校办学许可证号、年检状态 | 每年发布，含办学许可证号可间接证明独立法人 |
| **各区教育局招生计划/集团化办学文件** | 各区教育局官网 | ★★★★☆ | 学校办学性质、集团身份、校区关系 | 如"XX中学XX校区"vs"XX区XX学校"的命名区分 |
| **民办非企业单位登记公示** | 各区民政局官网 / 广东省社会组织管理局 | ★★★★☆ | 民办学校民非登记信息 | 民办学校的民非登记号 |
| **爱企查 / 企查查 / 天眼查** | https://aiqicha.baidu.com / https://www.qcc.com / https://www.tianyancha.com | ★★★☆☆ | 民办学校工商/民非信息、信用代码 | 商业平台，数据来自官方登记但可能滞后；免费版信息有限 |
| **学校官网 / 官方公众号** | 各校官网 | ★★★☆☆ | 学校自我介绍、办学性质、历史沿革 | 学校自述，需交叉验证 |
| **权威新闻报道** | 南方+（https://www.nfnews.com）、金羊网（http://news.ycwb.com）、广州日报（https://news.dayoo.com） | ★★★☆☆ | 民转公、新校开办、集团化办学等事件报道 | 主流媒体报道，可信度较高但非原始登记文件 |

### 证据使用原则

1. **每个判定必须有可溯源来源 URL**，记录在 `evidence[]` 中。
2. **信用代码查不到时**，`legal_entity.credit_code` 置 `null`，并在 evidence 中标注"信用代码待核"。
3. **禁止编造**统一社会信用代码、法人名、年份。查不到就标 `null` / `待核`。
4. **多源交叉**：独立法人挂牌校的判定至少需要2个证据源（如教育局文件+新闻报道），或1个官方登记文件。
5. **证据优先级**：官方登记文件 > 教育局公告 > 权威媒体 > 学校自述 > 商业平台。

## 五、数据层 Schema 设计（向后兼容）

### 新增字段（每校）

在 `tier1_schools_all.json` 每所学校的对象中新增以下字段，**不删改现有字段**：

```json
{
  "entity_relation": "本部 | 同法人校区 | 独立法人挂牌校 | 待核",
  "tier1_eligible": true,
  "legal_entity": {
    "name": "法人登记名称（如：广州市执信中学）或 null",
    "credit_code": "18位统一社会信用代码或 null",
    "type": "事业单位法人 | 民办非企业单位 | 市属公办 | 区属公办 | 省属公办 | 待核"
  },
  "exclude_reason": "若 tier1_eligible=false，写明排除原因（如：独立法人挂牌校，借用XX品牌）；否则为 null",
  "evidence": [
    {"source": "来源名称", "url": "https://...", "note": "证据说明"}
  ],
  "opened_year": 2023
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `entity_relation` | string | 是 | 四类枚举，见第二节定义 |
| `tier1_eligible` | bool | 是 | 是否可计入第一梯队。独立法人挂牌校=false，其余=true（待核暂定true） |
| `legal_entity.name` | string/null | 是 | 事业单位法人证书/民非登记上的全称 |
| `legal_entity.credit_code` | string/null | 是 | 18位统一社会信用代码，查不到为null |
| `legal_entity.type` | string | 是 | 法人类型枚举 |
| `exclude_reason` | string/null | 是 | eligible=false时的排除理由，否则null |
| `evidence` | array | 是 | 证据列表，至少1条；含source/url/note |
| `opened_year` | int/null | 是 | 新建校区开办年份，非新建校区为null |

### tier1.js 透传字段

构建脚本将以下字段透传到 `tier1.js`（供地图页运行时消费）：
- `entity_relation`
- `tier1_eligible`
- `exclude_reason`
- `opened_year`

`legal_entity` 和 `evidence` 保留在源 JSON 中（数据量大、地图页不需要展示），不透传到 tier1.js。

### 向后兼容性

- 所有现有字段（name、rumor_tier、rumor_sources、conclusion、signals、aliases、coords等）**保持不变**
- 新增字段为附加属性，旧版地图页代码读取时会忽略未知字段，不影响现有功能
- HTML/地图页后续可通过 `school.tier1_eligible === false` 过滤挂牌校，通过 `school.entity_relation` 做分类展示

## 六、与 HTML 解耦的消费方式说明

### 本轮改动范围

- ✅ data/：JSON 新增字段 + tier1.js 重新生成（含新字段）
- ✅ scripts/：build 脚本透传新字段
- ✅ docs/：本方案文档
- ❌ apps/web/：**不动**（正被另一个 agent 优化中）

### 后续 HTML 消费方式（供参考，本轮不实施）

地图页可在 JS 中增加过滤逻辑：

```javascript
// 过滤独立法人挂牌校
const eligibleSchools = window.GZ_TIER1.schools.filter(s => s.tier1_eligible);

// 或按类别分色展示
schools.forEach(s => {
  if (s.entity_relation === '独立法人挂牌校') {
    marker.setIcon(grayIcon);  // 灰色标记，不计入梯队
  } else if (s.entity_relation === '同法人校区') {
    marker.setIcon(blueIcon);  // 蓝色标记，校区
  } else {
    marker.setIcon(redIcon);   // 红色标记，本部
  }
});

// 新建校区标注
if (s.opened_year) {
  popup += `<br>开办年份：${s.opened_year}（${2026 - s.opened_year + 1}届）`;
}
```

### 数据更新流程

1. 修改 `data/*/tier1_schools_all.json` 中的法人字段
2. 运行 `python3 scripts/build_tier1_js.py` 和 `python3 scripts/build_middle_tier1_js.py` 重新生成 tier1.js
3. 地图页自动读取最新 tier1.js（浏览器缓存需刷新）

### 调研中发现的修正项

1. **白云铁一修正为同法人校区**：原假设为区属独立校，经核验铁一官网、市教育局2026部门预算（"拥有越秀、番禺、白云三个校区"）、白云区2025招生计划均确认为市属铁一中学白云校区，同法人。
2. **太和第一小学修正为本部**：官方《白云区义务教育学校基本信息一览表》显示"和龙校区"属于太和第二小学，太和第一小学实为单校区镇属中心小学。
3. **协和学校合并年份为2022年**（非2021年）：协和小学2022年8月整体并入协和中学成立广州协和学校。
4. **华赋学校补充为挂牌校**：原名"华南师范大学附属太和实验学校"（华附系公参民），2022年更名，品牌渊源借自华附。
5. **玉泉学校判为本部**：黄埔区属公办九年一贯制（自有品牌，2016年建校），虽属玉岩教育集团成员但无名校品牌挂靠。

## 八、数据缺口与后续工作

1. **统一社会信用代码**：112校中绝大多数学校的信用代码尚未从官方平台获取，`legal_entity.credit_code` 暂为 `null`。后续需逐校在 https://www.cods.org.cn 查询补全。
2. **待核学校**：部分学校的法人关系需进一步核实（如白云铁一与铁一中学白云校区的关系、玉泉学校是否有品牌挂靠、体育东路小学兴国学校/海明学校的法人性质）。
3. **新建校区届数**：已标注 `opened_year` 的校区，可据此计算当前办学届数（2026 - opened_year + 1），用于评估"前2-3届差距大"的阶段。
4. **定期更新**：民转公政策、集团化办学调整可能改变学校法人关系，建议每学年更新一次。
5. **HTML 过滤**：本轮仅完成数据层字段就位，地图页的过滤/分色展示需待 apps/web 优化完成后另行实施。
