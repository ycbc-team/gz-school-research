# 广州学校升学路线调研

为孩子寻找合适升学路线的调研项目。系统性调研广州地区的学校与升学路径，综合考虑学校实力、入学方式、孩子特点与家庭条件，形成可执行的升学决策建议。

## 目录结构

```
.
├── apps/                    # 各端应用
│   ├── map/                 # 地图应用（web，Leaflet 引擎，广州七区小学分布）
│   │   ├── index.html       # 单文件页面，直接浏览器打开
│   │   └── assets/          # Leaflet 库（本地化，不依赖 CDN）
│   ├── web/                 # 预留：其他 web 应用
│   └── miniprogram/         # 预留：微信小程序
├── data/                    # 共享数据层（多端共用，勿各自复制）
│   ├── schools.js           # 浏览器端数据快照（window.GZ_SCHOOLS）
│   ├── schools-gz.json      # 原始数据快照（可复核）
│   └── README.md            # 数据字段、口径与更新方式
├── scripts/                 # 共享脚本
│   └── fetch_schools.py     # 数据采集脚本（输出到 data/）
├── docs/                    # 调研报告、分析文档、决策建议（待建）
├── notes/                   # 调研笔记、访谈记录（待建）
├── .env                     # 本地密钥（git 忽略，不入库）
└── README.md
```

## 地图应用（apps/map）

浏览器直接打开 `apps/map/index.html` 即可使用：

- 展示广州 7 区（荔湾 / 越秀 / 海珠 / 天河 / 白云 / 黄埔 / 番禺）619 所小学点位
- 区边界色块 + 各区数量图例统计
- 拖动 / 滚轮 / 双指缩放查看，悬停点位显示校名
- 视野锁定七区范围
- 纯本地数据渲染，不做实时请求；学校信息固定长期不变

## 数据

- 来源：高德地图 Web 服务 API，2026-09-08 快照（GCJ-02 坐标系）
- 共 619 所：荔湾 72 / 越秀 73 / 海珠 96 / 天河 93 / 白云 100 / 黄埔 88 / 番禺 97
- 限制：单区最多 100 所（高德单次检索上限），白云区可能未覆盖全部
- 更新：`python3 scripts/fetch_schools.py`（需 `.env` 中的 `AMAP_WEB_KEY`）

## 调研维度（建议）

- 学校类型：公办 / 民办 / 国际学校 / 其他
- 升学路径：学区 / 摇号 / 考试 / 国际路线等
- 学校实力：办学历史、师资、成绩、口碑
- 适配性：孩子特点、通勤距离、学费预算
- 时间节点：幼升小 / 小升初 / 中考 等关键节点
