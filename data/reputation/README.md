# 口碑 / 学校信号资料归档（reputation）

> 归档日期：2026-09-30 ｜ 归档原因：tier1 业务废弃，前端不再依赖与展示，文字资料全部归档于此。

## 背景

tier1（第一梯队口碑名单 / 学校信号）曾是项目早期的"民间口碑"业务：基于网传榜单、自媒体与公开资料整理小学 / 初中"第一梯队名校"名单，并附带学位预警、历史称号、教育集团、中考成绩等信号字段。其数据口径为**民间标签、非官方评价**，与项目后续"官方口径优先"的治理方向冲突：

- 2026-09-17 起 data/README 已判定 tier1 废弃：entities 对 tier1 的别名挂载被移除，仅存 tier1→entities 反查；
- 2026-09-30 正式废弃：前端（Web / 小程序）全部移除 tier1 依赖与展示；tier1 数据与口碑核验文档整体归档到本目录，不再参与任何运行时链路。

## 归档说明

- **仅归档，不删除证据**：以上文件保留原文件名与内容，便于回溯当年核验过程与来源；git 历史完整保留（`git mv` 迁移）。
- **不参与运行时链路**：`compact.mjs`、`@gz/shared`、Web / 小程序均不再引用本目录任何文件；`npm run check` 不再校验本目录数据。
- **替代口径**：学校客观事实（招生计划 / 升学路线 / 名额分配 / 录取线 / 教育集团 / 获奖）一律以 `data/` 下官方口径业务数据为准（小学招生 `primary/enrollment/`、初中招生 `middle/enrollment/`、升学通道 `linkage/`、录取线 `high/cutoff_score/`、教育集团 `registry/group/` 等）。初中升学信号（自招 / 指标到校 / 特控率）见 `linkage/dist/ranking_middle.json`。
- 若未来需要重新引入"口碑"类展示，应重新立项并按官方口径重建，不得直接复用本目录数据作为展示源。
