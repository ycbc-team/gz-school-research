# 学生竞赛获奖采集（data/awards/）

小/中/高全学段学生官方竞赛获奖数据。优先级：初中先做。

## 目录分层

| 目录 | 内容 |
| --- | --- |
| `raw/` | 政府原文留底（xls/xlsx/html 公示页），只保留有用文件，中间产物（zip/指导老师/组织奖）不提交 |
| `parsed/` | 解析产物（脚本从 raw 直出） |
| `src/` | 人工校正（黑白名单，每条附 reason+evidence_url） |
| `scripts/` | 解析脚本 |
| `dist/` | 运行时编译产物（school_id → 奖项聚合） |

## 匹配规则

- 名单学段确定（如"初中金种子组"）→ 只挂该学段 school_id
- 带括号校区名 → 精确匹配该校区
- 整体名 → 一对多，该学校所有同学段校区 school_id 都挂
- 区码校验：school_id adcode 与官方区属一致
- 少年宫/青少年宫等非学校排除
