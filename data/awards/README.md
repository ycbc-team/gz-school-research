# 学生竞赛获奖采集（data/awards/）

小/中/高全学段学生官方竞赛获奖数据。优先级：初中先做。

## 目录分层

按赛事分子目录，每个赛事自带 `raw/parsed/scripts/dist` 四层；顶层放跨赛事聚合与回归测试。

| 路径 | 内容 |
| --- | --- |
| `innovation/` | 广州市中小学生创新大赛（小学金点子组/初中金种子组/高中金苗子组） |
| `chuangke/` | 广州市中小学生科技创客电视大赛（小学组/中学组） |
| `science_literacy/` | 广州市中小学生科学素养大赛（小学/初中/高中） |
| `tech_sports/` | 广州市中小学生科技体育教育竞赛市级总决赛（2026，个人/团队，含测向年龄组） |
| `dist/detailed_records.json` | 全赛事明细聚合（Web 获奖详情页消费，仅含匹配到 school_id 的记录） |
| `scripts/build_detailed_records.py` | 明细聚合脚本（从各赛事 parsed 直出） |
| `test/` | 构建产物回归测试（快照基线） |

各赛事子目录：
- `raw/` 政府原文留底（xls/xlsx/html 公示页），只保留有用文件，中间产物不提交
- `parsed/` 解析产物（脚本从 raw 直出，每赛事一个 JSON，按年份/组别归档）
- `scripts/` 解析脚本（raw → parsed → dist/compiled.json）
- `dist/compiled.json` 运行时编译产物（school_id → 奖项聚合）

### tech_sports 落地口径（2026-09-29）

- 名单为 2026 市级总决赛参赛学生获奖公示名单（1387 条，个人 + 团队），列含参赛组别与所属区
- 组别→学段：小学组/小学组团队及测向 M10/W10/M12/W12 → primary；中学组/中学组团队及 M15/W15 → secondary（初中+高中不拆）；M18/W18 → high（18 岁组，单位均为高中/完全中学）
- 综合组/综合组团队（展演与挑战赛，同组混小学与中学）→ 学段无法判定，跳过匹配（47 条 skipped 含 19 条少年宫等非学校）
- 覆盖限制：实体表以 7 区为主，南沙/从化/增城/花都的小学及部分中学无实体，匹配不到（与其他竞赛一致，宁缺毋滥）；本名单命中南沙/从化/增城均为实体表已有学校（如广州外国语学校、香江学校）

## 构建与回归

```bash
python3 data/awards/innovation/scripts/build_innovation.py            # 创新大赛（raw → parsed + dist/compiled.json）
python3 data/awards/chuangke/scripts/build_chuangke.py                # 科技创客电视大赛
python3 data/awards/science_literacy/scripts/build_science_literacy.py # 科学素养大赛
python3 data/awards/tech_sports/scripts/build_tech_sports.py          # 科技体育教育竞赛（2026 市级总决赛）
python3 data/awards/scripts/build_detailed_records.py                 # 跨赛事明细聚合 → dist/detailed_records.json
python3 data/awards/test/test_awards_build.py                         # 回归测试（快照基线 + 关键学校归属断言）
```

`test/test_awards_build.py` 从已解析的赛事名单重建明细产物，比对语义摘要快照，并抽查关键学校归属（校区精确匹配、整体名一对多、品牌成员校排除、别名指向）。源文件或匹配规则变化会触发失败，需人工核对后再更新基线。

## 匹配规则

- 名单学段确定（如"初中金种子组"）→ 只挂该学段 school_id
- 中学组不拆初高（科技创客电视大赛、科技体育中学组）→ 统一挂 `secondary`，避免误挂单学段
- 测向年龄组（科技体育）→ M10/W10/M12/W12 挂 primary，M15/W15 挂 secondary，M18/W18 挂 high
- 带括号校区名 → 精确匹配该校区
- 整体名 → 一对多，该学校所有同学段校区 school_id 都挂
- 区码校验：school_id adcode 与官方区属一致（2026 小学/高中无区属列，跳过；市属/省属靠名称匹配）
- 品牌成员校（独立法人）排除
- 少年宫/青少年宫等非学校排除
- 学段混合无法判定的组别（如科技体育综合组）→ 跳过匹配，记录留 parsed 的 skipped
- 归属统一走 `registry/entity` 的 SchoolMatcher，不在各脚本内维护局部字符串规则
