# registry/affiliation —— 学校隶属关系（市属/局属/省属）与高中层级业务

**定位**：记录「广州市教育局直属事业单位」（市属/局属）与「广东省教育厅下属单位」（省属）的官方口径名单，并为高中业务提供人工调研层级源（`src/levels.json`，含省市属/区属/民办分类与特控率指标），为学校实体表 `entity/dist/entities.json` 提供**市属（局属）/省属归属标记**的权威来源，供详情页「隶属关系/主管部门」板块与省市属 vs 区属划分使用。

- 广州市教育局官网《广州市教育局直属事业单位列表》：https://jyj.gz.gov.cn/gk/zfxxgkml/zzjg/jgzn/content/post_10116380.html
  - 发布时间：2025-02-14 17:26:02；统计时间：2024-12-31（页面标注）

  - 采集日期：2026-09-30，raw 为官网 PDF 原文存档

## 口径说明

- **市属**：广州市教育局直属事业单位，涵盖高职院校、教辅单位（招考办/教育研究院/评估中心/电教馆/基建装备中心/卫生健康促进中心）、市属中学（广雅/执信/二中/六中/协和/铁一/华侨/外语/艺术/清华附中湾区）、特殊学校（启聪/启明/新穗/启新）与 8 所市属职业学校；与 2025 年广州市教育局部门预算下属单位口径一致，可交叉验证。
- **省属**：广东省教育厅部门预算下属单位 64 个，转录时按名称特征归类（`category` 为推断字段，非原文字段）：厅属事业单位 5、省属本科高校 26、省属高职院校 22、成人高校 2、**省属中职/专门学校 6**（电子职校、星海附中、广美附中、潜水学校、食品药品职校、培英职校）、**省属中小学 3**（广东实验中学、华南师范大学附属中学、华南师范大学附属小学）。
- **省属 vs 市属（中学口径）**：广州中考体系内省属普通高中仅华南师大附中（石牌/知识城校区）、广东实验中学（荔湾/白云校区）2 校 4 校区——以广州市招考办名额分配表「隶属」列为准（`data/linkage/`，本目录不重复转录）；市属高中 20 个校区见 `jyj_直属事业单位列表_2025-02-14.json`。
- **已知口径差异（`check_levels_affiliation.py` 一次性核验，2026-09-30）**：levels.json 标「市属」的 **广州大学附属中学** 不在 jyj 直属事业单位 32 单位名单内——广大附中由广州大学举办，行政上非市教育局直属事业单位；但招考办名额分配表「隶属」列归市属（招生/指标口径）。两套口径并存，levels 维持招生口径「市属」，待业务侧决定是否加注「市属（招生口径，非局属事业单位）」。
- 名单中「单位地址」（市属表）是法人/注册地址，不代表全部校区；校区级信息以 `data/poi/` 与 `entity/dist/entities.json` 为准。
