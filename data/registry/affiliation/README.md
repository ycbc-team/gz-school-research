# registry/affiliation —— 学校隶属关系（市属/局属）业务

**定位**：记录「广州市教育局直属事业单位」（即市属学校/局属单位的官方口径名单），为学校实体表 `entity/dist/entities.json` 提供**市属（局属）归属标记**的权威来源，供详情页「隶属关系/主管部门」板块与市属 vs 区属划分使用。当前为 raw 采集阶段。

## 目录结构

| 层 | 内容 |
| --- | --- |
| `raw/` | `jyj_直属事业单位列表_2025-02-14.html`（广州市教育局官网原始页面，32 个单位，含序号/单位名称/单位地址/联系电话） |
| `parsed/` | `jyj_直属事业单位列表_2025-02-14.json`（raw → 结构化转录：title/source_url/publish_date/stats_date/unit_count/units[]，转录忠实原文；多校区地址以换行分行，多电话原样保留） |
| `dist/` | （待建）合并后的局属/市属标记表，供下游 school_id 维度挂接 |
| `scripts/` | `parse_jyj_affiliation.py`（raw HTML → parsed JSON，幂等；序号 1–32 连续性校验，缺失即失败；`--out-dir` 供重放） |

## 数据源

- 广州市教育局官网《广州市教育局直属事业单位列表》：https://jyj.gz.gov.cn/gk/zfxxgkml/zzjg/jgzn/content/post_10116380.html
  - 发布时间：2025-02-14 17:26:02
  - 统计时间：2024年12月31日（页面标注）
  - 单位数：**32 个**（序号 1–32 连续）
  - 字段：序号、单位名称、单位地址、联系电话
  - 采集日期：2026-09-30，raw 为官网页面原文存档

## 口径说明

- 该名单为**广州市教育局直属事业单位**，即市属学校/局属机构的官方口径；涵盖高职院校（如广州卫生职业技术学院）、教辅单位（如市招考办、市教育研究院）、市属中学（广东广雅中学、市执信中学等）、特殊学校（启聪/启明/新穗/启新）与市属职业学校（旅游商务、医药、纺织服装、轻工、交通运输、信息技术、财经商贸、城市建设）。
- 注意区分：名单中的「单位地址」是法人/注册地址，不代表全部校区；校区级信息以 `data/poi/` 与 `entity/dist/entities.json` 为准。
- 与 2025 年广州市教育局部门预算（jyj 官网附件 10158670.pdf）列出的下属单位口径一致，可交叉验证。
