# 高中出口数据（transition）

研究广州各区属示范高中**高考出口水平**（特控率 / 985 / 211 / 大学录取分布）的业务目录。

## 数据口径（重要，2026-10 用户纪律）

- **只采用两类可信渠道**：①校方官方喜报（公众号 / 官网）；②正规媒体（广州日报 / 南方+ / 羊城晚报 / 信息时报 / 新快报 等）。
- **纯家长流传 / 网传一律剔除**（抖音 / 头条家长号 / 搜狐软文等）。历史已剔除项清单见 `docs/rejected-net-claims.md`。
- 特控率等出口数字**没有官方总表**，只能逐校拼喜报 + 媒体；2025 届各校喜报数字正规渠道系统性缺失（教育部禁令），正规媒体只系统性报道 2026 届（最新一届）数据。
- "一本录取名额数"这类高校 × 中学录取矩阵公开渠道**不存在**（中大综评 PDF 无中学列、华工只披露综评合计、暨大只给生源 TOP 榜、华师不披露）。
- 唯一拿到完整"中学 × 录取人数"的是**广东工业大学 2024 录取名单**（官方 PDF，精确到人、普通批为主、含所有通道），为本表广工列的数据源。
- 综评是高考录取的独立通道（高考 85% + 校测 15%），**不能当总数**，表中单独列示。

```

├── README.md                 # 本文件：目录说明与口径
├── raw/                      # 官方原始文件（只进不改）

│   └── sysu_2025_zongping.pdf     # 中大 2025 综合评价录取名单（官方 PDF，无中学列，仅考生号）
├── parsed/                   # raw 的文本转录（脚本产物）
│   └── sysu_2025.txt              # 中大综评 pdftotext 转录（考生号前 6 位可统计到区级）
├── dist/                     # 派生 JSON（脚本产物，勿手改；改脚本须重跑）
│   └── gdut_2024_school_counts.json  # 广工 2024 各高中录取人数（all=全部 1609 校 / guangzhou=广州 103 校）
├── src/                      # 人工维护的源数据 / 口径说明（若有）
├── scripts/                  # 可复现解析脚本
│   └── parse_gdut_pdf.py     # 广工 PDF 坐标解析状态机（含 43 所区属示范回归校验，见脚本内 known 字典）
├── test/                     # 面向用户的可读交付物（唯一最新版）
│   └── 区属高中出口矩阵.html # 7 区 43 所区属示范高中出口矩阵（含广工 2024 / 中大区级 / 华工综评 / 2026 届媒体披露）
└── docs/                     # 口径说明与剔除清单
```

## 各文件作用

| 文件 | 作用 | 更新方式 |
| --- | --- | --- |
| `raw/gdut_2024_enrollment.pdf` | 广工 2024 录取名单官方原件（招办 zsb.gdut.edu.cn，声明录取本科新生 10191 名） | 人工下载，只进不改 |
| `raw/sysu_2025_zongping.pdf` | 中大 2025 综评名单官方原件（493 人） | 人工下载，只进不改 |
| `parsed/sysu_2025.txt` | 中大综评转录文本，考生号前 6 位正则 `\b25(44\d{4})\d{6}\b` 可统计到广州各区 | `pdftotext` 重跑 |
| `dist/gdut_2024_school_counts.json` | **唯一数据真源**：广工 2024 各高中录取人数（`all` 全国 1609 校 / `guangzhou` 广州 103 校），HTML 广工列由此生成 | `python3 scripts/parse_gdut_pdf.py` 重跑 |
| `scripts/parse_gdut_pdf.py` | 广工 PDF 解析器：坐标三列布局（学校名 x≈88-180 / 人数 x≈208 / 名单 x≈239）状态机，处理跨行拆名、人数嵌段、括号续接、跨页补全；内置 43 所区属示范 `known` 校验字典 | 改后须重跑并核对 43 所全过 |
| `test/区属高中出口矩阵.html` | **唯一最新交付物**：43 所区属示范出口矩阵（荔湾/越秀/海珠/天河/白云/黄埔/番禺），列：2026 中考户籍分 / 2026 届官方媒体披露 / 华工综评 / 中大区级 / 广工 2024 / 985-211 信号 | 随 dist JSON 更新手工同步广工列 |
| `docs/rejected-net-claims.md` | 已剔除的网传数据清单（勿再采信/复用） | 发现新网传项即追加 |

## 43 所区属示范名单来源

`apps/web/src/data/compact/high/level/src/levels.js`（`category=="区属示范"` 恰好 43 所；七区：荔湾 5 / 越秀 7 / 海珠 5 / 天河 7 / 白云 7 / 黄埔 4 / 番禺 8）。录取分排序见 `data/high/cutoff_score/dist/scores_2026.json`（2026 年第三批户籍生）。

## 已知缺口

- 2025 届各校特控率等喜报数字正规渠道系统性缺失（校方只在公众号/家长圈发布，正规媒体不报道），HTML 中相关格标"未披露"。
- 高校 × 中学录取矩阵仅广工 2024 拿到完整数据；中大综评只能到区级；华工综评仅媒体披露部分中学。
- 广工 PDF 解析后全国名单仍有少数括号/繁体边缘拼接残片（均为非广州学校，不影响 43 所核心校验），43 所区属示范全部通过回归校验。
