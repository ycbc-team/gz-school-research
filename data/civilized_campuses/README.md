# 文明校园称号采集（data/civilized_campuses/）

全国、广东省、广州市文明校园及其创建培育名单的原始资料与后续解析产物。
本目录独立于 `specialty_schools`：文明校园是覆盖立德树人、师德、校园文化、环境与治理的
综合荣誉，不归入单项特色学校称号。

## 当前阶段：仅收集原始资料

本阶段先将正式名单原件及其来源说明落入 `raw/`，**不预设最终 JSON 字段、不写解析结果、
不生成 dist**。待对不同届次、不同级别名单的学校名称、校区表达、复查/保留规则和可获得的
名单字段完成核查后，再确定 `parsed/` 的真源格式与构建逻辑。

首轮已落盘：全国第一至三届正式名单、第一届广东省正式名单，以及第二届广东省候选/往届
复查公示和广州“创建文明校园先进学校”名单。后二者只用于观察来源结构和后续追溯，不能作为
正式认定数据。

首批范围：

1. 第一至第三届全国文明校园正式名单（中国文明网）；
2. 广东省文明校园的正式表彰/复查名单；
3. 广州市文明校园及“创建广州市文明校园先进学校”等名单（后者须与正式认定明确区分）。

## 目录约定（先建分层，不代表已有数据）

| 目录 | 当前用途 |
| --- | --- |
| `raw/` | 原始网页、附件、下载记录与来源索引；本轮唯一写入的数据层 |
| `parsed/` | 后续确定字段后存放逐校真源；当前为空 |
| `src/` | 后续人工校对、别名或补充真源；当前为空 |
| `scripts/` | 下载、解析、构建脚本；当前为空 |
| `dist/` | 运行时编译产物；当前为空 |
| `test/` | 解析和完整性断言；当前为空 |

## 原始资料判定规则

- 优先保存签发/发布机关的正式“决定、公布、表彰、复查确认”页及附件；公示、推荐、创建先进
  学校单独留存，不能写作正式文明校园。
- 每个原件必须有来源 URL、抓取日期和文件说明，放在同目录 `SOURCES.md`。
- 全国文明校园每届期满需复查；后续设计数据时必须能表达届次与“新命名/复查保留/撤销或未知”，
  不能把历史名单直接当作永久有效状态。
- 名单出现校区、部别或集团时保留原文，待解析阶段再通过 `SchoolMatcher` 判定可否关联学校实体。
