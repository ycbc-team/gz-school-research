# 初中客观信号采集（data/middle/details/）

替代已废弃的 tier1 口碑数据，只采集**政府文件可直出的客观事实**。

## 目录分层（严格纪律）

| 目录 | 内容 | 谁可改 |
| --- | --- | --- |
| `raw/` | 政府原文留底（html/xls/pdf），文件名带来源文号+年份 | 只增不改，下载即留底 |
| `parsed/` | 解析产物 JSON（脚本从 raw 直出，含 school_id 匹配结果） | **禁止手改**，跑脚本重生成 |
| `src/` | 人工校正（黑白名单）——脚本误收/漏收的修正 | **唯一允许人工改的层**，每条必须附理由+依据 URL |
| `scripts/` | 解析脚本（build_*.py） | 改脚本须重跑 parsed + compiled |
| `dist/` | 运行时编译产物（parsed ∪ src） | 脚本生成，禁止手改 |

## 匹配纪律

- 政府名单学校名 → school_id：去行政区前缀规范化 + **区码校验**（school_id 前 6 位 adcode 必须与官方 region 一致）
- 同名跨区不采纳，进 `src/` 人工校正
- 7 区外（南沙/从化/增城/花都）不在项目范围，unmatched 是预期
